# 18. RS-232 제어

## 18.1.  개요

UART(Universal Asynchronous Receiver and Transmitter)는 비동기 통신의 스펙을 정의한 것이다.  흔히 말하는 RS-232C는 데이터 전송 방법을 말한다. RS-232C의 방법으로 PC와 PC, PC와장비 또는 장비와 장비를 연결하는 데는 TxD와 RxD, GND의 세 라인의 연결만이 필요하다.

시리얼 통신의 속도를 나타내는 baud rate는 1 초당 전송되는 단위 신호의 수를 나타낸다.RS-232C 인터페이스에서는 이 baud rate와 전송 속도(bps: bit per second)가 일치하기 때문에단위로서 baud 또는 bps가 사용된다.

아래 그림은 일반적인 RS-232C 통신의 데이터 흐름을 나타낸 것이다.

회선에서 데이터가 흐르지 않는 휴지기에는 데이터가 ‘1’의 값을 유지한다. 데이터 통신이 시작 될 때 시작 비트로 1 비트가 ‘0’의 값을 가지며, 이후의 값은 8비트의 실제 데이터가 전송된다. 데이터의 전송 후에 Parity bit가 전송 되는데, 이 parity bit는 옵션으로 사용 여부와ODD, EVEN parity bit를 사용할 것인지를 설정하여 사용할 수 있다. Parity bit까지의 데이터 전송 후에는 정지 비트로 ‘1’의 값을 1 비트 또는 2비트까지 유지시켜 주는 것으로 1 프레임의데이터 전송을 마친다. 전송이 끝난 후에는 ‘1’의 값을 유지해 주어야 한다. 이 흐름의 방식은RxD와 TxD가 동일하게 이루어 진다.

## 18.2.  기본 제어

아래 RS232 제어 예제는 UART를 통해 시리얼 통신을 실험하는 예제이다. 여기에서는 컴퓨터와 장비간의 시리얼 통신 실험을 위해 케이블을 연결하고 Windows에 있는 하이퍼 터미널을통해 통신 실험을 확인할 수 있다. 이 예제는 장비의 클럭을 분주하여 컴퓨터의 전송 속도와일치 시켜 주는 작업을 하고, 컴퓨터에서 오는 문자 또는 문장을 FPGA에서 받아 다시 컴퓨터로 보내 주는 작업을 한다. 따라서 하이퍼 터미널을 통해 입력된 문자 코드를 전송하면 케이블을 통해 FPGA로 전달이 되고 이 전달된 값을 다시 컴퓨터로 전송을 하여 하이퍼 터미널 창에 표시된다.

이 로직은 TOP PROJECT로 CH3_RS232_TOP가 설계되어 있으며, RS232 통신을 위한CH3_RS232로직을 COMPONENT로 사용한다.

10MHz의 클럭의 입력을 받아, RS232C의 통신속도로 115,200bps를 사용하고 있다. 따라서하이퍼 터미널의 전송 속도는 115,200bps로 설정해야 한다. 장비의 클럭과 전송속도는 로직을수정해야 설정을 달리 할 수 있습니다.

```verilog
// CH3_RS232_TOP.V
module CH3_RS232_TOP(RESETN, CLK,PARITY_EN, PARITY_MODE,RXD,TXD);
input RESETN, CLK;
input PARITY_EN, PARITY_MODE;
input RXD;
output TXD;
wire [7:0] UART_DATA_IN;
wire [7:0] UART_DATA_OUT;
wire RXD_EN;
wire TXD_EN;
reg [7:0] REG_RXD_EN;
reg [7:0] REG_DATA_IN0;
reg [7:0] REG_DATA_IN1;
reg [7:0] REG_DATA_IN2;
reg [7:0] REG_DATA_IN3;
reg [7:0] REG_DATA_IN4;
reg [7:0] REG_DATA_IN5;
reg [7:0] REG_DATA_IN6;
reg [7:0] REG_DATA_IN7;
CH3_RS232 U_RS_232(RESETN, CLK,PARITY_EN, PARITY_MODE,RXD,TXD,RXD_EN,TXD_EN,UART_DATA_IN, UART_DATA_OUT);
always @(posedge CLK)
begin
    if (~RESETN)
        REG_RXD_EN = 8'b00000000;
    else
        REG_RXD_EN = {REG_RXD_EN[6:0], RXD_EN};
end
assign TXD_EN = REG_RXD_EN[7];
always @(posedge CLK)
begin
    if (~RESETN)
    begin
        REG_DATA_IN0 = 8'b00000000;
        REG_DATA_IN1 = 8'b00000000;
        REG_DATA_IN2 = 8'b00000000;
        REG_DATA_IN3 = 8'b00000000;
        REG_DATA_IN4 = 8'b00000000;
        REG_DATA_IN5 = 8'b00000000;
        REG_DATA_IN6 = 8'b00000000;
        REG_DATA_IN7 = 8'b00000000;
    end
    else
    begin
        REG_DATA_IN0 = UART_DATA_IN;
        REG_DATA_IN1 = REG_DATA_IN0;
        REG_DATA_IN2 = REG_DATA_IN1;
        REG_DATA_IN3 = REG_DATA_IN2;
        REG_DATA_IN4 = REG_DATA_IN3;
        REG_DATA_IN5 = REG_DATA_IN4;
        REG_DATA_IN6 = REG_DATA_IN5;
        REG_DATA_IN7 = REG_DATA_IN6;
    end
end
assign UART_DATA_OUT = REG_DATA_IN7;
endmodule
```

위의 로직은 RS232 방식으로 시리얼 통신을 위한 예제의 TOP PROJECT 파일이다.

7 ~ 18라인에 외부에서 RESETN의 입력과 10MHz의 클럭의 입력을 받고, RXD와 출력인 TXD 단자를 통해서 시리얼 통신 할 수 있도록 입출력 단자가 선언되었다.
  
22 ~ 38라인은 실제 RXD로 들어온 데이터를 8비트의 병렬 데이터로 만들고, 8비트의 병렬 데이터를 1비트씩 TXD에 출력하는 CH3_RS232 로직을 COMPONENT로 선언하는 블록이다.57~72라인에서 이 COMPONENT와 TOP PROJECT가 PORT MAP으로 연결되어 있다.

74~108라인은 이 예제가 RXD로 받은 데이터를 TXD로 전송하는 로직이기 때문에, RXD의 1바이트 수신 완료의 신호인 RXD_EN의 신호와 이 때 받은 8비트의 RXD 데이터를 일정 시간 지연 후, TXD_EN으로 전달시키는 부분이다. 시프트 레지스터가 설계되어, RXD_EN의 신호가 8클럭 후 TXD_EN의 신호로 전송되도록 구성되어 있다. 이것은 여러 데이터가 연속적으로 들어왔을 때, RXD로 받은 데이터를 TXD로 바로 전달하지 못하는 경우가 있는데, 이런 통신이 끊어지는 현상을 막는 버퍼의 역할을 하도록 구성되어 있다.

```verilog
// CH3_RS232.V
module CH3_RS232(RESETN, CLK,PARITY_EN, PARITY_MODE,RXD,TXD,RXD_EN,TXD_EN,UART_DATA_IN, UART_DATA_OUT
input RESETN, CLK;
input PARITY_EN, PARITY_MODE;
input RXD;
output TXD;
output RXD_EN;
input TXD_EN;
output [7:0] UART_DATA_IN;
input [7:0] UART_DATA_OUT;
reg TXD;
reg RXD_EN;
reg [7:0] UART_DATA_IN;
parameter [7:0] BIT_RATE = 8'b01010110;      // 10M / 115200 = 86
parameter [7:0] BIT_RATE_HALF = 8'b00101011; // 43
parameter RX_IDLE = 3'b000, RX_START = 3'b001, DATA_RX = 3'b010, RX_PARITY = 3'b011, RX_STOP = 3'b100;
parameter TX_IDLE = 3'b000, TX_START = 3'b001, DATA_TX = 3'b010, TX_PARITY = 3'b011, TX_STOP = 3'b100;
reg [2:0] RX_ROUTINE;
reg [2:0] TX_ROUTINE;
reg [7:0] RX_BIT_ADD;
reg [7:0] CNT_RX_BIT_RATE;
reg [2:0] CNT_RX_DATA;
reg [7:0] CNT_TX_BIT_RATE;
reg [2:0] CNT_TX_DATA;
reg [7:0] RX_DATA;
reg [7:0] TX_DATA;
reg [15:0] REG_RXD;
reg TX_PARITY_CHK;
always @(posedge CLK)
begin
    if (~RESETN)
        REG_RXD = 16'b0000000000000000;
    else
        REG_RXD = {RXD, REG_RXD[15:1]};
end
always @(posedge CLK)
begin
    if (~RESETN)
        RX_BIT_ADD = 8'b00000000;
    else if (RX_ROUTINE == DATA_RX)
    begin
        if (CNT_RX_BIT_RATE == BIT_RATE)
            RX_BIT_ADD = 8'b00000000;
        else
            RX_BIT_ADD = RX_BIT_ADD + REG_RXD[0];
    end
    else
        RX_BIT_ADD = 8'b00000000;
end
always @(posedge CLK)
begin
    if (~RESETN)
        RX_ROUTINE = RX_IDLE;
    else
        case (RX_ROUTINE)
            RX_IDLE:
                if (REG_RXD == 16'b0000000000000000)
                    RX_ROUTINE = RX_START;
            RX_START:
                if (CNT_RX_BIT_RATE == BIT_RATE)
                    RX_ROUTINE = DATA_RX;
                else if (CNT_RX_BIT_RATE == BIT_RATE_HALF)
                    if (REG_RXD[0] == 1'b1)
                        RX_ROUTINE = RX_IDLE;
            DATA_RX:
                if (CNT_RX_DATA == 3'b111)
                    if (CNT_RX_BIT_RATE == BIT_RATE)
                        if (PARITY_EN == 1'b1)
                            RX_ROUTINE = RX_PARITY;
                        else
                            RX_ROUTINE = RX_STOP;
            RX_PARITY:
                if (CNT_RX_BIT_RATE == BIT_RATE)
                    RX_ROUTINE = RX_STOP;
            RX_STOP:
                if (CNT_RX_BIT_RATE[5:0] == BIT_RATE[7:2])
                    RX_ROUTINE = RX_IDLE;
        endcase
end
always @(posedge CLK)
begin
    if (~RESETN)
        CNT_RX_BIT_RATE = 8'b00000000;
    else if (RX_ROUTINE == RX_IDLE)
        CNT_RX_BIT_RATE = 8'b00000000;
    else if (CNT_RX_BIT_RATE == BIT_RATE)
        CNT_RX_BIT_RATE = 8'b00000000;
    else
        CNT_RX_BIT_RATE = CNT_RX_BIT_RATE + 1'b1;
end
always @(posedge CLK)
begin
    if (~RESETN)
        CNT_RX_DATA = 3'b000;
    else if (RX_ROUTINE == DATA_RX)
    begin
        if (CNT_RX_BIT_RATE == BIT_RATE)
        begin
            if (CNT_RX_DATA == 3'b111)
                CNT_RX_DATA = 3'b000;
            else
                CNT_RX_DATA = CNT_RX_DATA + 1'b1;
        end
    end
    else
        CNT_RX_DATA = 3'b000;
end
always @(posedge CLK)
begin
    if (~RESETN)
        RX_DATA = 8'b00000000;
    else if (RX_ROUTINE == DATA_RX)
    begin
        if (CNT_RX_BIT_RATE == BIT_RATE - 1)
        begin
            if (RX_BIT_ADD >= BIT_RATE_HALF)
                RX_DATA = {1'b1, RX_DATA[7:1]};
            else
                RX_DATA = {1'b0, RX_DATA[7:1]};
        end
    end
    else if (RX_ROUTINE == RX_IDLE)
        RX_DATA = 8'b00000000;
end
always @(posedge CLK)
begin
    if (~RESETN)
        RXD_EN = 1'b0;
    else if (RX_ROUTINE == RX_STOP)
    begin
        if (CNT_RX_BIT_RATE >= 10)
            RXD_EN = 1'b1;
        else
            RXD_EN = 1'b0;
    end
    else
        RXD_EN = 1'b0;
end
always @(posedge CLK)
begin
    if (~RESETN)
        UART_DATA_IN = 8'b00000000;
    else if (RX_ROUTINE == RX_STOP)
        UART_DATA_IN = RX_DATA;
end
always @(posedge CLK)
begin
    if (~RESETN)
        TX_ROUTINE = TX_IDLE;
    else
        case (TX_ROUTINE)
            TX_IDLE:
                if (TXD_EN == 1'b1)
                    TX_ROUTINE = TX_START;
            TX_START:
                if (CNT_TX_BIT_RATE == BIT_RATE)
                    TX_ROUTINE = DATA_TX;
            DATA_TX:
                if (CNT_TX_DATA == 3'b111)
                    if (CNT_TX_BIT_RATE == BIT_RATE)
                        if (PARITY_EN == 1'b1)
                            TX_ROUTINE = TX_PARITY;
                        else
                            TX_ROUTINE = TX_STOP;
            TX_PARITY:
                if (CNT_TX_BIT_RATE == BIT_RATE)
                    TX_ROUTINE = TX_STOP;
            TX_STOP:
                if (CNT_TX_BIT_RATE == BIT_RATE - 10)
                    TX_ROUTINE = TX_IDLE;
            default:
                TX_ROUTINE = TX_IDLE;
        endcase
end
always @(posedge CLK)
begin
    if (~RESETN)
        CNT_TX_BIT_RATE = 8'b00000000;
    else if (TX_ROUTINE == TX_IDLE)
        CNT_TX_BIT_RATE = 8'b00000000;
    else if (CNT_TX_BIT_RATE == BIT_RATE)
        CNT_TX_BIT_RATE = 8'b00000000;
    else
        CNT_TX_BIT_RATE = CNT_TX_BIT_RATE + 1'b1;
end
always @(posedge CLK)
begin
    if (~RESETN)
        CNT_TX_DATA = 3'b000;
    else if (TX_ROUTINE == DATA_TX)
    begin
        if (CNT_TX_BIT_RATE == BIT_RATE)
        begin
            if (CNT_TX_DATA == 3'b111)
                CNT_TX_DATA = 3'b000;
            else
                CNT_TX_DATA = CNT_TX_DATA + 1'b1;
        end
    end
    else
        CNT_TX_DATA = 3'b000;
end
always @(posedge CLK)
begin
    if (~RESETN)
        TX_DATA = 8'b00000000;
    else if (TX_ROUTINE == TX_IDLE)
    begin
        if (TXD_EN == 1'b1)
            TX_DATA = UART_DATA_OUT;
    end
end
always @(posedge CLK)
begin
    if (~RESETN)
        TX_PARITY_CHK = 1'b0;
    else if (TX_ROUTINE == TX_IDLE)
    begin
        if (TXD_EN == 1'b1)
            TX_PARITY_CHK = UART_DATA_OUT[7] ^ UART_DATA_OUT[6] ^ UART_DATA_OUT[5] ^ UART_DATA_OUT[4] ^ UART_DATA_OUT[3] ^ UART_DATA_OUT[2] ^ UART_DATA_OUT[1] ^ UART_DATA_OUT[0] ^ PARITY_MODE;
    end
end
always @(posedge CLK)
begin
    if (~RESETN)
        TXD = 1'b1;
    else
        case (TX_ROUTINE)
            TX_IDLE:
                TXD = 1'b1;
            TX_START:
                TXD = 1'b0;
            DATA_TX:
                if (CNT_TX_DATA == 3'b000)
                    TXD = TX_DATA[0];
                else if (CNT_TX_DATA == 3'b001)
                    TXD = TX_DATA[1];
                else if (CNT_TX_DATA == 3'b010)
                    TXD = TX_DATA[2];
                else if (CNT_TX_DATA == 3'b011)
                    TXD = TX_DATA[3];
                else if (CNT_TX_DATA == 3'b100)
                    TXD = TX_DATA[4];
                else if (CNT_TX_DATA == 3'b101)
                    TXD = TX_DATA[5];
                else if (CNT_TX_DATA == 3'b110)
                    TXD = TX_DATA[6];
                else if (CNT_TX_DATA == 3'b111)
                    TXD = TX_DATA[7];
                else
                    TXD = 1'b1;
            TX_PARITY:
                TXD = TX_PARITY_CHK;
            TX_STOP:
                TXD = 1'b1;
            default:
                TXD = 1'b1;
        endcase
end
endmodule
```

위의 로직에서 86 ~ 198라인은 RXD의 데이터 입력을 받아 8비트의 데이터로 변환시키는 송신블록이 설계되어 있고, 200 ~ 340라인은 외부에서 받은 8비트의 데이터 입력을 TXD로 1비트데이터씩 전송시키는 수신 블록이 설계되어 있다.

먼저 27 ~ 28라인은 시리얼 통신의 BAUD RATE를 설정하기 위한 한계 카운트 값을 설정하는부분이다. 10MHz의 클럭입력을 받아 115200BPS의 속도를 생성하기 위하여 계산한 결과이다.

30 ~ 34라인은 RXD와 TXD의 통신의 흐름을 스테이트 머신으로 구성한 부분이다. 각각 IDEL,START BIT, DATA, PARITY, STOP BIT의 상태로 구성되어 있다.

RXD 수신 블록에서 52~77라인은 START BIT를 검출하기 위한 블록이다.

79 ~ 117라인은 RXD 블록의 스테이트 머신을 동작시키는 블록으로, 위에서 검출한 STARTBIT(클럭이 16번일 때까지 RXD의 값이 0일 때)을 감지하는 블록이다. 노이즈에 의해 잠깐RXD의 신호가 0으로 떨어질 수 있기 때문에 일정구간을 연속적으로 0이 들어올 때까지를 감지하도록 구성되어 있다. 시리얼 통신에서 1비트를 받는 속도가 115200BPS인데, 이것은10MHz의 클럭으로는 87번 카운트해야 같은 속도가 나온다. 그래서 카운트 값이 87번을 초과하지 않는 범위 최대 절반 값인 44번을 카운트 할 때까지 RXD의 값이 0으로 유지되면 STARTBIT인 것으로 인정하고 DATA를 받아들이는 상태로 넘어가게 된다. DATA RX 상태에서 8개의데이터를 받은 후, PARITY 비트 체크 입력이 들어올 때는 PARITY BIT 상태로 아니면 RX의STOP 상태로 변경하도록 구성되어 있다. STOP 상태일 때 일정 구간 동안 1의 값이 유지되면다시 IDEL 상태로 바뀌어 RXD의 입력을 기다리는 상태로 돌아간다.

119 ~ 132라인은 10MHz의 클럭을 카운트하여 115200BPS의 속도를 만드는 블록이다.

134 ~ 151라인은 RXD 수신 블록이 DATA RX상태일 때, 8비트의 데이터를 받기 위해 이 값을카운트하는 블록이고, 153~170라인은 PARITY BIT를 체크하는 블록이다. 172 ~ 187라인은 RXD의수신이 종료되면 RXD_EN에 1의 값을 출력하는 블록이다.

200 ~ 235라인은 TXD 송신 블록에서 스테이트 머신을 동작시키기 위한 블록이다. 이 TXD 송신블록은 IDLE상태에서 TXD_EN의 신호를 받아 동작한다. 그리고, 115200BPS의 속도에 맞춰서START BIT, DATA TX상태로 넘어간다. PARITY 비트 ENABLE에 따라 TX PARITY 상태로 넘어가거나 STOP 상태로 넘어간다. 그리고, 일정 시간 후에 IDEL 상태로 넘어가도록 설계되어 있다.

238 ~ 251라인에서TXD의 115200 BPS의 속도를 계산하도록 CNT_TX_BIT_RATE를 카운트시킨다.

253 ~ 270라인에서는 DATA TX상태에서 8개의 데이터를 전송하기 위한 TXD 데이터의 개수를카운트한다.

272 ~ 283라인에서 TXD_EN의 신호가 1일 때 외부에서 들어온 8비트 TXD 전송 데이터의 값을TX_DATA 는 변수에 저장시키고, 285 ~ 300라인은 TXD 데이터의 PARITY 비트를 생성하는 블록이다.

302 ~ 340라인에서 TXD 전송 블록의 각 상태일 때 실제 UART에 TXD에 데이터를 전송하는 블록이다.

아래 테스트 벤치 파일이 이 예제를 시뮬레이션을 하기 위해서 예제에서 필요로 하는 입력신호를 생성하기 위한 것이다.

```verilog
// TB_CH3_RS232_TOP.V
`timescale 10ns / 1ps

module TestBench;

    // input
    reg  RESETN, CLK;
    reg  PARITY_EN, PARITY_MODE;
    reg  RXD;
    // output
    wire TXD;

    // Instantiate the U1
    CH3_RS232_TOP U_CH3_RS232_TOP(RESETN, CLK,PARITY_EN, PARITY_MODE,RXD,TXD);

    always
    begin
        #10 CLK = ~CLK;
    end

    initial
    begin
        CLK = 1'b0;
        RESETN = 1'b0;
        PARITY_EN = 1'b0;
        PARITY_MODE = 1'b0;
        RXD = 1'b1;
        #15 RESETN = 1'b1;
        #85 RXD = 1'b0;
        #2900 RXD = 1'b1;
        #2000 RXD = 1'b0;
        #2000 RXD = 1'b1;
        #2000 RXD = 1'b0;
        #2000 RXD = 1'b1;
    end

endmodule
```

이 테스트 벤치 파일은 34~46라인에서 CH3_RS232_TOP의 입력 신호인 RESETN과 CLK, RXD신호를 생성하는 블록이 구현되어 있다.

45 ~ 46라인은 PC에서 전송하는 RXD 신호를 생성하는 구문으로, 임의의 데이터를 생성하도록구성되어 있다.

아래 그림은 ModelSim 소프트웨어로 시뮬레이션 한 결과를 나타낸다. RXD로 입력받은 데이터를 그 대로 TXD로 출력하는 것을 보여준다.
