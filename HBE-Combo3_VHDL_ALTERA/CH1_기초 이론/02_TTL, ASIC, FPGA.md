## 2.1. 개요

디지털 시스템을 구성하는데 사용하는 직접회로(Integrated Circuit)는 크게 범용 IC와 ASIC으로 분류할 수 있다. 범용 IC는 일반적으로 TI 또는 HITACHI와 같은 반도체 생산업자가 시스템에서 많이 사용되는 회로를 개발, 양산하여, 사용자가 이러한 칩을 이용하여 시스템을 구성하도록 한다. 예를 들면 74 시리즈와 같은 TTL이나 8051 Microprocessor등이 이 범용 IC 그룹에속한다고 볼 수 있다.ASIC(Application Specific IC)는 사용자가 요구하는 기능을 만족시키는 IC를 시스템 업체나 디자인 하우스 등에서 설계하고, 반도체 제조 공정에서 칩으로 생산하여 특정 용도에 맞도록 사용한다. 즉, 사용자가 요구하는 특정 용도로 동작하도록 설계된 IC를 의미한다.이 절에서는 위에서 소개한 TTL과 ASIC 그리고, FPGA에 대한 소개와 각각의 특징에 대하여설명하도록 하겠다.

## 2.2. TTL, ASIC, PLD

### (1) TTL (Transistor Transistor Logic)

TTL은 논리 게이트를 내장한 널리 사용되고 있는 종료의 IC이다. 또, 종류도 다양하게 있어서용도에 맞는 IC를 선택하여 사용할 수 있다. 이 TTL이 Transistor Transistor Logic의 약자이듯이다수의 트렌지스터에 의해 논리 게이트를 구성하고 있다. 보통 사용하는 TTL은 74시리즈를 많이 사용한다.아래 그림은 각각 AND 게이트가 4개로 이루어진 7408의 내부 블록도와 트랜지스터에 의해구성된 AND 게이트의 모습을 나타내고 있다.같은 7408 IC라고 하더라도 74LS08, 74S08등의 품명이 있으며 이 품명은 아래와 같은 특징을갖고 있다.시리즈 명특 징전달 지연시간소비 전력클럭 입력주파수74 시리즈표준 TTL10ns10mW0 ~ 35 MHz74L 시리즈저전력 TTL33ns1mW0 ~ 3 MHz74H 시리즈고속 TTL6ns22mW0 ~ 50 MHz74S 시리즈Schottky TTL3ns19mW0 ~ 125 MHz74LS 시리즈저전압 Schottky TTL95ns2mW0 ~ 45 MHz74AS 시리즈Advanced SchottkyTTL15ns22mW0 ~ 200 MHz74ALS 시리즈저전력 Advanced TTL4ns1mW0 ~ 100 MHz이외에도 74F 시리즈, 74HC 시리즈 등이 있다.74시리즈는 현재 0번부터 시작하여 600번 대까지의 제품이 나와 있으며, 기본 게이트 종류에서부터 디코더, 플립플롭, 레지스터, 카운터 등 많은 종류가 포함되어 있다.분 류종 류0 ~ 30 번대게이트41 ~ 48 번대디코더70 번대플립 플롭80 번대가산기90 번대카운터, 레지스터200 번대, 300 번대100 번대 이하의 개량

### (2) ASIC (Application Specific IC)

ASIC은 특정한 전자·정보통신 제품에 사용할 목적으로 설계된 비 메모리 반도체 칩이다. 이것은 전자제품을 제조하는 업체가 반도체 설계 업체에 개발을 주문하는 형태로 제작되는데, 전자제품의 성능을 좌우하는 핵심 기능을 포함한다.ASIC은 사용자가 요구하는 규격에 따른 기능 설계가 가능하기 때문에 아래와 같은 장점을 갖고 있다.z제품의 고집적화, 소형 경량화, 성능 향상z저전력화, 시스템 기술 보호z경쟁력 강화z신뢰성 향상을 통한 부품의 최적화, 공정의 단순화, 자동화z기능의 복합화에 대처z고성능의 작고, 가벼운 제품을 만드는 유일한 방안위와 같은 장점이 있는 반면에, 설계된 ASIC이 범용적으로 사용되지 않고, 제작 공정 기간에대한 아래와 같은 단점을 포함하고 있다.z초기 개발 비용(NRE)과 개발 시간이 많이 소요됨.z설계 실패에 대한 부담감 과중(비용, Time-To-Market 지연 등)z목표 변경에 따른 수정이 어렵고, 수량이 적을 시 가격 고가ASIC은 설계 공정에 따라 Gate Array, Standard Cell, Full Custom IC 공정으로 구분되며, 각각아래와 같은 특징과 장단점을 갖고 있다. Gate Array반주문형 설계 대규모 집적 회로(LSI)의 하나로, 다품종 소량 생산형 LSI이다. 규칙적으로 병렬배치된 논리 소자인 게이트를 미리 설계해 두고, 이들 게이트 사이를 배선하기 위한 마스크를설계하는 방법으로 사용자가 요구하는 LSI를 개발 할 수 있다. 개발비가 적게 들고, 상대적으로 개발 소요시간이 적게 드는 장점은 있지만, Full Custom IC보다 집적도가 낮은 특징을 갖고있다.z장점 : Full Custom IC의 개발 방식에 비에 절반 정도의 제조 시간이 걸린다. Digitalsystem을 구현하기에 적합하며, 사용자는 반도체 공정 기술에 관한 전문 지식이 필요없는 Logic Engineer이면 된다.z단점 :  standard cell이나 full-custom IC에 비해 silicon 면적을 비효율적으로 많이 사용(약 die의 75%가 routing 영역, 25%가 gate 영역)하여 Die 비용이 높다. 또한 전력소모가 크고 스위칭 속도가 떨어진다. Standard Cell위의 Gate Array와 같이 반주문형 집적 회로의 하나이다. 미리 작성된 표준 기능 블록(Cell)등을 조합하여 사용자의 요구에 맞도록 설계되는 특징을 갖고 있다. 일반적으로 CAD 시스템을이용하여 자동 설계된다. Full Custom IC와 Gate Array의 중간적인 특징을 갖고 있다.z장점 : Gate Array보다 효율적인 silicon영역을 사용하며 silicon 전달 거리가 줄어들어chip 속도가 향상된다.z단점 : 본질적인 Processing cost 부담이 없으므로 설계 비용이 증가하나, 대량 생산 시비용이 감소하는 이점이 있다. Gate Array 방법에 비해 개발 속도가 느리다. Full Custom ICGate Array와 Standard Cell에 의한 IC 공정과는 다르게 모든 공정을 직접 설계하는 주문형LSI이다. 모든 설계과정을 일일이 수작업으로 Design한다. 개발 소요 비용과 시간은 가장 많이들지만, 전기적 성능과 실리콘 면적의 사용도가 극대화 된다는 장점을 갖고 있다.z장점 : 대량 생산 시 저가격으로 최고 성능의 chip을 얻을 수 있다.z단점 : 설계 시간이 많이 걸리고, 설계를 위한 고급 전문 인력이 필요하며, NRE cost가많이 든다. ASSP (Application Specific Standard Products)특정용도 또는 응용을 대상으로 하는 전용 표준 제품의 집적 회로(IC)나 LSI를 말하는 것으로,각종 컴퓨터 주변기기 또는 통신용 controller 등이 대표적이다.이것은 처음에는 특정 사용자의 요구에 의해 반도체 제조 회사가 신규로 제작한 IC 인데, 이IC의 평판이 좋아 일반 사용자에게 판매되고, 또, 전용 표준 제품이 되어서 생겨나는 경우가많다.

### (3) PLD (Programmable Logic Device)

ASIC의 단점에 대한 대안으로 PLD을 사용한 IC 개발 및 제품의 개발이 활발하게 이루어지고있다.PLD 초기에는 ASIC으로 설계한 로직의 일부분을 PLD에 프로그래밍하여 하드웨어의 테스트를위한 용도로 많이 사용되었다. 하지만, 기술이 점점 발전하여 PLD의 설계 용량이 늘어나고 저전력에 대한 솔루션 등이 발전함에 따라, 제품의 초기 모델과 소량의 제품인 경우에는 PLD를이용한 제품의 생산이 되는 경우가 있다.ASIC에서 사용하는 로직의 일부분을 테스트하는 것이 아니라, ASIC으로 사용하고자 하는 로직을 FPGA에서 구현하여 테스트하고 이렇게 테스트한 결과를 ASIC으로 바로 적용할 수 있는솔루션들이 개발되어 있다.사용자에 의해서 내부 내용을 자유롭게 바꾸어 설계할 수 있는 칩이다. 반도체 제조 업자의측면에서는 양산되어 일반적인 용도로 사용되므로 범용 IC라 할 수도 있고, 사용자 측면에서는 사용자 요구에 맞도록 설계가 가능하기 때문에 ASIC이라고도 할 수 있다.z장점 : 설계와 프로그래밍을 위한 장비의 비용이 적게 든다. 프로그래밍의 시간이 짧으며,설계 수정이 쉽다. NRE 비용이 들지 않는다.z단점 : silicon 면적의 사용이 비효율적이고, 개별 단가가 비싸다.

## 2.3. FPGA Architecture

이 절에서는 HBE-Combo III 장비에서 사용하는 ALTERA FPGA 디바이스의 하드웨어 특징에 대하여 간단하게 설명하고 있다. FPGA의 내부 Architecture에 대해서 자세하게 알아두면 좋지만,그 특징을 이해하는 데에도 시간이 많이 걸리기 때문에 실제로 장비에 사용하는 Cyclone IIFPGA Device가 갖고 있는 주요 특징과 기본 Architecture에 대해서 간략하게 설명하도록 하겠다.다음의 그림은 이 Cyclone II 디바이스의 내부 Architecture에 대한 블록도이다. 여기에서 볼수 있듯이 Cyclone II 내부 구조는 크게 로직을 설계하는 부분은 논리 게이트가 설계되는Logic Array Block과 데이터를 저장할 수 있는 장소인 메모리가 구성되는 M4K Block, 그리고신호처리 부분에서 연산의 속도를 올려주기 위한 Embedded Multipliers Block으로 나누어 진다. 이 외에 디바이스 외부의 입 출력을 위한 IOEs 블록과 클럭을 관리해 주는 PLL 블록이 구성되어 있다. Logic Element아래의 그림은 FPGA를 구성하는 가장 기본 블록인 Logic Element의 내부 구조를 보여주는 그림이다. 사용자가 FPGA를 이용하여 회로 또는 시스템을 설계하였다면, 설계한 회로 또는 시스템에서 사용되는 논리 회로가 이 Logic Element에서 구성된다.위의 Logic Element 블록도에서 보이듯이 Logic Element는 크게 Look-Up Table(LUT)과Programmable Register, Routing 선으로 이루어지는 것을 알 수 있다. LUT는 논리회로가 구성되는 곳이다. LUT는 다른 Logic Element 또는 IO의 입력 신호를 4개 받아서 출력시키는 구조로 구성되어 있다. 4개 이상의 입력 신호를 받는 논리 회로의 경우에는 LUT 옆에 붙어 있는Carry Chain을 통해서 다른 Logic Element와 연결되어 회로가 구성된다. 또, 플립플롭이 사용되는 회로의 경우에는 Logic Element에 포함되어 있는 플립플롭을 사용하도록 구성된다. LUT와 플립플롭을 거쳐서 만들어진 신호는 Routing 신호선을 통해서 다른 Logic Element 또는FPGA의 Routing Bus로 이루어진 있는 Interconnection Bus에 연결되도록 구성되어 있다.보통 1개의 Logic Element에는 약 20개의 논리 게이트가 합성되지만, 그렇다고 해서 AND 게이트를 20개를 사용하였을 때 1개의 Logic Element에 구성된다는 말은 아니다. 이 LogicElement는 FPGA내에 수만~수십만개가 구성되어 있다. LAB(Logic Array Block)위의 Logic Element는 각각 1개씩 FPGA에 구성되어 있지 않다. 아래 그림에서 처럼 16개의Logic Element가 묶여져서 구성되는 Logic Array Block으로 FPGA는 구성된다. LAB와 LAB는Interconnection Bus를 통해 연결된다.이 Interconnection Bus는 아래 그림과 같이 Row와 Column Interconnect Connection으로 구성되어 FPGA내에 LAB를 더 많이 구성할 수 있도록 도와준다. M4K RAM Block아래 그림은 FPGA 내부에서 메모리를 설계하는데 최적화되도록 구성된 M4K RAM Block에 대한 블록도이다.Logic Element에도 플립플롭이 구성되어 있기 때문에 이 Logic Element를 사용해서 메모리를설계할 수 도 있지만, 회로의 최적화와 동작 속도를 빠르게 하기 위해서는 M4K RAM Block을사용하는 것이 좋다. 일반적으로 사용하는 메모리는 IC로써 하드웨어 적으로 구성되기 때문에Address와 Data의 비트 수가 고정되어 있는데, FPGA 내에 구성된 M4K RAM Block은 일정 메모리의 용량을 갖고 있지만, Address와 Data의 비트 수는 가변적이다. 예를 들어 1개의 M4KRAM Block은 약 4kbit의 메모리를 설계 할 수 있는데, 이것은 4kbit = 4 x 1024 = 4096개의데이터를 저장할 수 있음을 의미한다. 만약 4비트의 데이터를 저장하는 메모리를 설계할 경우에는 총 1024개의 address를 갖고 있는 메모리를 설계할 수 있다. 같은 용량을 두고 8비트의데이터를 사용할 경우에는 512개의 address를 갖는 메모리를 설계할 수 있다.즉, 4096 = 4 bit X 1024 = 8 bit X 512 = 16 bit X 256 = … 의 구성이 가능해 진다.물론 FPGA내에 M4K RAM Block이 여러 개 구성되어 있기 때문에 설계되는 용량이 4kbit를초과할 경우에는 다른 Block과 연결되어 FPGA에서 지원하는 메모리 용량까지 설계할 수 있다.또, M4K RAM Block는 Interconnect Connection과 연결되어 있어서 이 블록을 필요로 하는 로직과 빠르게 연결할 수 있도록 구성되어 있다. Embedded Multiplier Block아래의 그림은 Cyclone II 내부에 구성되어 있는 Embedded Multiplier Block의 블록도를 나타낸 것이다.1개의 Embedded Multiplier Block에는 18bit X 18bit곱셈 연산을 할 수 있는 블록이 구성되어있다. 사용하는 방법에 따라서 1개의 블록에서 9bit X 9bit 곱셈 연산 2개를 구성도 가능하다.이것은 DSP와 같은 신호처리 시스템을 설계하거나, 연산을 많이 하는 시스템을 설계할 때 도움이 많이 된다. M4K RAM Block과 마찬가지로, 이런 연산회로를 Logic Element로 설계할 수도 있지만, 설계의 최적화와 동작 performance의 향상을 위해서 이런 연산을 위한 전용 블록인 Embedded Multiplier Block이 Cyclone II 디바이스 내부에 구성되어 있다. Cyclone II Device Feature아래의 표는 Cyclone II 디바이스 Family의 특징을 보여주는 표이다.
