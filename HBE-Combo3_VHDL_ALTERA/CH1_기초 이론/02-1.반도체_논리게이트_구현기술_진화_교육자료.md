## 1. 서론

논리 게이트는 **입력 신호의 크기에 따라 출력 전압을 High/Low로 스위칭**하는 아날로그 증폭기의 일종이다. 모든 논리 패밀리는 다음 3가지 물리적 제약을 어떻게 풀었는가에 따라 구분된다.

| 문제 | 내용 | 대표 지표 |
|---|---|---|
| **속도 (Switching speed)** | 기생 용량을 충/방전하고, 캐리어 축적(포화 전하)을 제거해야 한다 | 전파 지연 $t_{pd}$, 상승/하강 시간 $t_r, t_f$ |
| **전력 (Power)** | 게이트가 소모하는 전력과 밀도가 트레이드오프 | 정적 전력 $P_{DC}$, 동적 전력 $P_{dyn}$ |
| **집적도 (Density)** | 소자 하나 당 차지하는 실리콘 면적 | 게이트당 소자 수, 면적 |

지금까지의 진화 요약:

```
1947 트랜지스터 발명
1950s  RTL (첫 집적 게이트, TI)
1961   DTL  (TI)
1963   TTL  (TI, 멀티에미터 BJT) + CMOS 발명(Fairchild) ← 같은 해!
1965   ECL  (Motorola MECL-I)
1970s  I²L (IBM)
1970s  PMOS → NMOS (Intel 8086)
1980s  CMOS 표준화 (74HC)  + BiCMOS
2000s  FinFET (Intel 22nm, 2011 상용화)
2020s  GAA / 나노시트 (삼성 3nm, 2022)
```

## 2. 바이폴라 논리 패밀리

> 공통 개념: **BJT를 스위치로 사용**. BJT는 순방향 포화 시 베이스에 과잉 소수캐리어(minority carrier)가 축적되므로, 꺼질 때 이 전하를 빼내는 데 시간이 걸린다 → **포화 방지(saturation clamping)**가 속도 개선의 핵심.

### 2.1 RTL — 저항-트랜지스터 로직

**구조**: 저항 네트워크 + NPN BJT

```
   VCC
    |
   R_C
    |
    o----- V_OUT
    |
  Q1 (NPN, C)
  |   베이스
  |-R_B1-- V_IN1
  |
  |-R_B2-- V_IN2
  |
  E
  |
 GND
```

- 동작: $V_{IN}$이 $V_{BE(on)} \approx 0.6$V 이상이면 Q1 포화 → $V_{OUT} = V_{CE(sat)} \approx 0.1 \sim 0.2$V (LOW). 모든 입력이 LOW면 Q1 컷오프 → $V_{OUT} = V_{CC}$ (HIGH).
- NOR 구조이다. (어느 입력이든 High면 출력 Low)
- **단점**: 변칙적 조합 문제 — 병렬 베이스 저항 때문에 여러 입력이 HIGH일 때 베이스 전압이 올라가 오동작. 잡음 마진 0.4V로 매우 낮음. 출력 LOW 전압이 $V_{CE(sat)}$에 의존해 온도·부하에 예민.

**파라미터 (RTL형, TI SN74L 계열 기준)**

| 파라미터 | 값 |
|---|---|
| 전원공급 $V_{CC}$ | 3.6~5.5 V |
| 전파지연 $t_{pd}$ | ~50 ns |
| 정적 전력($V_{OH}$) | ~10 mW |
| 잡음 마진 | ~0.4 V |
| 팬아웃 | ~5 |
| 로직 (typ) | NOR |

---

### 2.2 DTL — 다이오드-트랜지스터 로직

**구조**: 입력부를 다이오드로, 출력부를 BJT로 대체

```
        VCC
         |
      R_C |       ┌──────────────┐
         o────────┴─D3      R2   │
         |          │ L     │    │
        D1──V_IN1   │ L     ┘    │
        D2──V_IN2   │            Q2(C,b,e)
        D3     │ D4  │           │
         └─────┴─────┴──(node A)─┤ b
                   |              │
                  GND           e─┴─GND
```

- 입력 다이오드가 모두 LOW로 클램프 → 노드 A가 LOW → Q2 컷오프 → $V_{OUT}=V_{CC}$ (HIGH).
- 하나라도 HIGH → 노드 A 상승, Q2 포화 → $V_{OUT} \approx 0.2$V (LOW). **NAND 기능**.
- 잡음 마진은 다이오드 강하 $V_{D} \approx 0.7$V 기반으로 RTL보다 개선.
- **단점**: 다이오드의 기생 정전용량이 스위칭을 느리게 만든다 (몇 백 ns).

**파라미터 (DTL, 74 계열)**

| 파라미터 | 값 |
|---|---|
| $V_{CC}$ | 4.75~5.25 V |
| $t_{pd}$ | ~30 ns |
| 정적 전력 | ~8 mW |
| 잡음 마진 $V_{NM}$ | ~0.7 V |
| 팬아웃 | ~8 |

---

### 2.3 TTL — 트랜지스터-트랜지스터 로직 (심화)

**핵심 혁신**: 입력 다이오드를 **멀티에미터 트랜지스터(Multi-emitter BJT)** 하나로 통합. 다이오드 개수가 줄어, 기생 용량 감소 → DTL보다 약 5배 빠르고, IC 집적에 유리.

#### 2.3.1 표준 TTL (시리즈 7400)

**표준 TTL NAND 게이트 (2입력)** 구조:

```
                    VCC (5V)
                     |
                   R1(4kΩ)         R2(1.6kΩ)     R4(130Ω)
                     |               |              |
        V_IN1 o────b|e1         Q2   |        Q3     |
        V_IN2 o────b|e2   Q1   |   b─┘        b──────┘(출력스테이지)
                     |         |               |
                    e──────────┘출력           e──┬──o V_OUT
                     |         |               |  └── D(쇼트키다이오드, 보호)
                     |         |               R3(1kΩ)
                     |         e              └──────┘
                     |         |
                     |        GND             GND
                    GND
```

| 소자 | 전류경로 설명 |
|---|---|
| Q1 (멀티에미터) | 입력부. 에미터가 논리 인에이블. 입력이 LOW면 Q1 포화되어 Q2 베이스 전하를 빨아냄(빠른 해제) |
| Q2 (위상분리기, phase splitter) | 하나의 입력으로 Q3/Q4를 상보적으로 구동 |
| Q3(상부 토템폴) + D | 토템폴(totem-pole) 상단: Q3 ON → HIGH 출력 |
| Q4(하부 토템폴) | Q4 ON → LOW 출력 |
| D (쇼트키 다이오드) | Q3이 깊은 포화에 빠지지 않도록 클램프 |

**동작 메커니즘**: (표준 TTL 참고치)

1. **두 입력 모두 HIGH(≥2V)** → Q1의 에미터-베이스 역방향, Q1 베이스-콜렉터 순방향 → Q1을 거쳐 Q2 베이스 구동 → Q2 ON → Q3 포화, Q4 컷오프 → $V_{OUT}=V_{OH}\approx 3.4$V.
   *(짚어보기: "에미터가 HIGH면 Q1은 '역방향으로' 동작한다.* **이때 멀티에미터의 입력수 2개를 병렬로 묶지 않는 한, 입력을 서로 떠 있는 상태로 두면 안 된다 — 플로팅 입력은 Q1이 ON이 되어 오동작.*)*
2. **어느 입력이라도 LOW(≤0.8V)** → 해당 에미터 순방향 → Q1 포화, Q2 베이스가 낮게 유지 → Q2 컷오프 → Q3 컷오프, Q4 포화 → $V_{OUT}=V_{OL}\approx 0.2$V.

**토템폴 출력(Totem-pole)의 장점**
- 출력이 HIGH일 때와 LOW일 때 모두 **저임피던스 경로** → 기생 용량 충/방전이 빨라 $t_r, t_f$ 감소.
- 단점: Q3/Q4가 동시에 잠깐 켜지는 **이미지 전류(크로스바 전류)** 발생 → 순간 전류 스파이크 → 전원 배선에 바이패스 콘덴서 필수.

**파라미터 (표준 TTL 7400)**

| 파라미터 | 조건 | 값 |
|---|---|---|
| $V_{CC}$ | — | 4.75~5.25 V |
| $I_{OH}$ (HIGH 출력 전류) | $V_{OH}=2.4V$ | −0.4 mA |
| $I_{OL}$ (LOW 출력 전류) | $V_{OL}=0.4V$ | 16 mA |
| $V_{IH}$ / $V_{IL}$ | — | 2.0 V / 0.8 V |
| $V_{OH}$ / $V_{OL}$ | — | 2.4 V / 0.4 V |
| $t_{pd}$ | — | **~10 ns** |
| 정적 전력 | — | **~10 mW** |
| 팬아웃 (fanout) | — | 10 |

> **성능지수(전력×속도)**: TTL 계열은 전력-지연 곱(PD product)으로 서열을 매긴다. 아래 표 참조.

#### 2.3.2 입력보호·무연결 주의

- 입력에 **음극 보호 다이오드(EBC 다이오드)** 를 사용해 정전기(ESD)/네거티브 스파이크로부터 Q1 에미터-베이스 보호.
- **플로팅 입력 금지**: 멀티에미터 Q1은 입력을 "내부 풀업"하지 않으므로(표준 TTL), 입력을 공중에 두면 Q1이 포화되어 Q4가 켜져 LOW 출력이 나옴. -한 입력이라도 반드시 +5V나 GND에 연결해야 한다.

### 2.4 TTL 변형 — 쇼트키(74S), 저전력쇼트키(74LS), ALS, FAST

#### 2.4.1 쇼트키 스위치 (Schottky switch) 원리

BJT가 포화되면 캐리어 축적으로 **turn-off 지연**이 생긴다. 이를 막는 두 방법:

1. **쇼트키 다이오드 클램프**: BJT의 B-C 단자에 쇼트키 다이오드를 병렬 연결.
   - 쇼트키 다이오드는 금속-반도체 접합이라 저장 전하가 거의 없음 + 순방향 강하(~0.3V)가 BJT($V_{BC(on)} \approx 0.6V$)보다 낮음.
   - 베이스 전류가 쇼트키 다이오드로 분로되어, 콜렉터 전압이 $V_{CE(sat)} \approx 0.3V$ **이상으로는 내려가지 못함** → 포화가 되기 전에 클램프.
   - 결과: 깊은 포화 방지 → 저장시간(εlectronic storage time) 제거 + 유지 저전력.

2. **베이스 기동 시 유도 전류 보정(active pull-down)** — 주로 NAND 쪽에서 Q1로 Q2 베이스를 적극적으로 빠르게 방전.

**쇼트키 클램프 TTL 구조 요약**

```
   VCC
    |
  R1 ────┐
         |         Q3(b) ─ Q3(e) ─(R4)─ V_OUT
    Q1 (멀티에미터)  └ D_S──┐     └ D_S(클램프)→ V_OUT
         |                  |
   ...  Q2                Q4(b) ─ Q4(e) ─ GND
```

각 BJT($Q_1 Q_2 Q_3 Q_4$)에 쇼트키 다이오드 $D_S$ 병렬 연결.

#### 2.4.2 TTL 계열 특성 비교표 (동일 7400 NAND, $V_{CC}=5V$)

| 파라미터 | 74 (표준) | 74L (저전력) | 74S (쇼트키) | 74LS (저전력쇼트키) | 74ALS | 74F (FAST) |
|---|---|---|---|---|---|---|
| $t_{pd}$ (ns) | 10 | 33 | 3 | 9.5 | 5 | 3 |
| 전력 (mW) | 10 | 1 | 19 | 2 | 1.2 | 4 |
| **PD 곱 (pJ)** | **100** | 33 | 57 | 19 | 6 | 12 |
| 델타 입력 전류 $\Delta I_{IH}$ | 40 µA @$V_{IH}=2.4V$ | 10 µA | 50 µA | 20 µA | 20 µA | 20 µA |
| $I_{OL}$ (mA) | 16 | 2 | 20 | 8 | 8 | 20 |
| 팬아웃 | 10 | 10 | 10 | 10 | 20 | 20 |

**해석**: 74LS가 총력(PD=19pJ)에서 가장 우수한 수지상 → 74LS 시리즈가 20여 년간 전 세계 표준이 된 이유. 74F는 74S의 속도 + LS의 전력을 타협.

### 2.5 ECL — 에미터 결합 로직 (고속의 끝)

**핵심 아이디어**: 트랜지스터를 **절대 포화시키지 않는다**. 공통 에미터 차동증폭기(differential pair)로 항상 선형영역에서 동작 → 저장 전하 제로 → 나노초 이하 스위칭.

**구조 (OR/NOR 게이트)**

```
          VCC (GND 기준)
           |
      R_C1 R_C2
        |     |
   o────┘     └─────o        Q1..Q_n : 입력단(NOR)
   |                    |        Q2 : 기준(reference) 입력
  Q1 ── b o V_IN1       Q2
   |                        |━━ V_REF = -1.29V (typ)
   └─────┐    ┌──────┘
         └────┘
           | 낮은 저항률
          R_E (밀러 효과 감소)
           |
          VEE = -5.2V
```

- 왼쪽 입력(OR 부분)이 기준전압보다 높으면 Q1측 ON → $V_{R_C1}$ 낮아짐 → OR 출력 **LOW**. 기준보다 낮으면 R_C1쪽 컷오프 → OR 출력 HIGH.
- 출력은 **오픈 에미터 이미터폴로워(emitter follower)** 로 내려가 구동력 확보. 그래서 ~50Ω 전송선을 직접 구동 가능.
- **왜 빠른가**:
 1. 비포화 → 저장 지연 제로
 2. 전압 스윙이 작다: $V_{pp} \approx 0.8$V (200mV 논리 구간) → 기생 용량 충/방전이 미미
 3. 전류가 **상시 일정(정전류 동작)** → 전원 리플이 로직 레벨에 영향을 안 줘 스위칭 동안 안정
- **단점**: 상시 전류 소모 → 전력이 매우 큼 (~25mW/게이트). 통신 고속, 슈퍼컴퓨터(CDC 6600~), 고속 카운터 등 한정.

**파라미터 (MECL 10K 시리즈, $V_{EE}=-5.2V$)**

| 파라미터 | 값 |
|---|---|
| $t_{pd}$ | 1~2 ns |
| 전력 | 25 mW/게이트 |
| PD 곱 | ~50 pJ (74LS보다 나쁨! 전력 때문에) |
| 전압 스윙 | ~0.8 V |
| 잡음 마진 | 0.1~0.2 V (나쁨 → 배선 주의 필요) |

> ECL은 "속도는 최고, 전력은 최악" → 현대에선 초고속 광통신(MUX/DEMUX), 테스트장비, RF 프론트엔드에서만 존속. GaAs 등 화합물 반도체 고속 로직과 경쟁.

### 2.6 I²L — 고집적 바이폴라 (Integrated Injection Logic)

- 개요: 1970년대 IBM이 개발. **트랜지스터를 포화시켜서** 작게 만드는 바이폴라 방식.
- 구조: "주입형(injector)" pnp가 캐리어를 주입하고, 무콜렉터 n-epi를 사용 → **저항 없이** 팬아웃 구성. BJT 수가 극히 적어(1소자/게이트) 집적도가 매우 높음. 그러나 바이폴라 특유의 느린 포화 지연 + 낮은 전압 스윙(그래서 속도는 TTL보다 느림).
- 응용: 계산기, 시계, 그리고 후에 BiCMOS 내부의 고밀도 부분.

## 3. MOS 논리 패밀리

### 3.1 PMOS / NMOS

**왜 MOS인가?**
- MOSFET는 **게이트 산화막($SiO_2$) 위의 정전용량 구동** → 게이트 전류가 거의 0(A급에서) → 소신호 이득이 높고, 베이스 전류가 필요 없는 BJT와 달리 동적 구동이 쉬움.
- 단점: 초기 MOS는 문턱전압이 높고, P형 이동도 $\mu_p \approx 400$cm²/V·s가 전자($\mu_n \approx 1200$)의 1/3 → 속도가 느렸다.

**PMOS 게이트 (예: NOR)**

```
   VDD
    |
  ┘S₁ ────────o (부하: 부하 트랜지스터, 포화)
   |     V_OUT
  ┐D₁
   |      o──── V_IN1
   | G₁
  ┌──┐
   D₂ ─ o──── V_IN2
  └S₂ ─┘── GND
```

- 입력 HIGH(0V) → 드라이버 ON → 출력 $V_{OL}=\frac{R_{ds}}{R_{ds}+R_L}V_{DD}$ (전압분배) → **저항 부하 때문에 LOW 레벨이 불완전**. 고대역~소자가 항상 전류를 흘림 → 정적 전력 큼.

**NMOS 게이트 (살리사이드 시기, 8086 CPU)**

- 1970년대 후반 이후 PMOS를 대체 → 전자 이동도가 높아 2~3배 빠름. 음전원 필요 없음(+5V).
- 부하 방식에 따라 정적 전력 차이:
  - 강화형 부하(NMOS): 위와 같은 저항성 → 정적 전력 큼.
  - **디플리션 부하(MOSFET D-mode)**: 위의 저항식이 **상시 전류원** → 간단.
- 여전히: 출력 High 때 부하가 전류를 흘리므로 정적 전력 존재.

**파라미터 (NMOS, 1980년대)**

| 파라미터 | 값 |
|---|---|
| $V_{DD}$ | 5 V |
| $V_{TN}$ | ~0.6~0.8 V |
| $t_{pd}$ | 5~20 ns |
| 정적 전력 | ~2 mW (디플리션 부하) |
| 게이트 용량 | $\approx C_{ox}WL$ |

## 4. CMOS와 현대 논리

### 4.1 CMOS 인버터 구조와 동작

**핵심**: PMOS 풀업 + NMOS 풀다운을 **상보(Complementary)** 조합. 한쪽이 ON이면 다른 쪽 OFF → **VDD에서 GND로의 직류 경로가 없음 = 정적 전력 유사 0**.

```
            VDD
             |
          ┐ PMOS (p-channel)
   V_IN ──┤ G
          ┌
             |
             o──── V_OUT
             |
          ┐
   V_IN ──┤ G NMOS (n-channel)
          ┌
             |
            GND
```

**동작 4분할 (VTC 분석에 중요)**

| 입력 구간 | PMOS | NMOS | 출력 |
|---|---|---|---|
| $V_{IN} < V_{TN}$ | ON (선형) | OFF (컷오프) | HIGH $=V_{DD}$ |
| $V_{TN} < V_{IN} < V_M$ | ON→ 포화 | OFF→ 포화(개시) | 하강 시작 |
| $V_M < V_{IN} < V_{DD}-|V_{TP}|$ | 포화 | 포화 (스위칭 중앙) |
| $V_{IN} > V_{DD}-|V_{TP}|$ | OFF | ON → LOW $=0$ |

### 4.2 정적 특성 — VTC 및 노이즈 마진

**스위칭 임계전압 $V_M$** (인버터의 중간점에서 $V_{OUT}=V_{IN}$):

$$
V_M = \frac{V_{TN} + \sqrt{ \frac{\mu_n W_N / L_N}{\mu_p W_P / L_P} } \left( V_{DD} + V_{TP} \right) }{ 1 + \sqrt{ \frac{\mu_n W_N / L_N}{\mu_p W_P / L_P} } }
$$

- 대칭 VTC하려면 $\mu_p \approx \mu_n/3$ 이므로 **$W_P \approx 2.5\sim3 W_N$** 로 보상 → 스위칭 시 NMOS와 PMOS의 구동 전류가 동일해짐.

**노이즈 마진 (Noise Margin)**

$$
NM_H = V_{OH} - V_{IH} \quad,\quad NM_L = V_{IL} - V_{OL}
$$

CMOS는 $V_{OH}\approx V_{DD}$, $V_{OL}\approx 0$ → $NM_H, NM_L \approx$ 수 십 % VDD로 모든 논리 중 최대.

- 게이트센터 근방의 기울기가 가파를수록($-dV_{OUT}/dV_{IN}$↑) 이득 높아져 노이즈 마진 ↑.
- **롱채널(Long-channel) CMOS 인버터 VTC 자세 수식**

| 구간 | $V_{OUT}$ 관계 (근사) |
|---|---|
| 컷오프 | $V_{OUT} = V_{DD}$ |
| NMOS 선형/PMOS 포화 | $K_n\left[(V_{IN}-V_{TN})V_{OUT}-\frac{V_{OUT}^2}{2}\right] = \frac{K_p}{2}(V_{DD}-V_{IN}+V_{TP})^2$ |
| 둘 다 포화 (지점) | $V_M$ 검출 공식으로 해석 |
| PMOS 선형/NMOS 포화 | $K_p\left[(V_{DD}-V_{IN}+V_{TP})(V_{DD}-V_{OUT})-\frac{(V_{DD}-V_{OUT})^2}{2}\right]=\frac{K_n}{2}(V_{IN}-V_{TN})^2$ |

여기서 $K_n=\mu_n C_{ox}\frac{W_n}{L_n}$, $K_p=\mu_p C_{ox}\frac{W_p}{L_p}$.

### 4.3 동적 특성 — 전파 지연과 전력

**전파 지연 $t_{pd}$** (부하용량 $C_L$, 귀환용량 미미하다고 가정):

$$
t_{pd} \approx \frac{C_L \, V_{DD}}{2\, I_{avg}}
  = \frac{C_L}{\mu_n C_{ox}\frac{W}{L} (V_{DD}-V_T)}
$$

- 지연은 **부하 용량에 비례, 구동전류에 반비례**. → 팬아웃/배선 기생 용량이 느린 이유.

**전력 소모 3종**

$$
P_{total} = \underbrace{\alpha C_{load} V_{DD}^2 f}_{P_{dynamic}}
           + \underbrace{I_{sc} V_{DD}}_{P_{short-circuit}}
           + \underbrace{I_{leak} V_{DD}}_{P_{static}}
$$

| 항 | 물리적 근원 | 특징 |
|---|---|---|
| $P_{dyn} = \alpha C_L V_{DD}^2 f$ | 부하용량 충/방전 | $\alpha$: 스위칭 활동도(0~1), $f$: 클록 주파수 |
| $P_{short}$ | 상승/하강 중 PMOS/NMOS 동시 ON 돌입전류 | 스윙 시간에 비례, VTC 기울기로 제어 |
| $P_{static}$ | 오프 누설 전류 $I_{OFF}$: 서브문턱 누설 $I_{sub}$, 게이트누설 $I_{gate}$, 접합누설 $I_{jt}$ | 공정 축소로 기하급수적 증가 → **FinFET로 해결** |

**서브문턱 누설 전류** (가장 중요한 정적 누설):

$$
I_{sub} = I_0 \exp\left( \frac{V_{GS} - V_{TH}}{n V_T} \right) \left[ 1 - \exp\left( -\frac{V_{DS}}{V_T} \right) \right]
$$

- DIBL(drain-induced barrier lowering)에 의해 $V_T$가 단축채널의 $V_{DS}$ 증가로 낮아져 누설 급증 → 아래 §6 참조.

### 4.4 CMOS 논리 패밀리 시리즈 비교 (74HC/HCT/AC/ACT)

| 특성 | 74HC | 74HCT | 74AC | 74ACT | 74LVC | 74AUP |
|---|---|---|---|---|---|---|

## 5. BiCMOS

- 정의: **CMOS 로직 코어 + 바이폴라 출력 버퍼**.
- 왜? CMOS는 큰 후배선 LTS 부하($C_L$ 큰 배선)를 구동할 때 구동전류가 $I \propto \frac{W}{L}$로 키우는 데 한계가 있고, BJT는 출력 임피던스가 낮아 고전류 구동에 유리.
- 구조:

```
   CMOS 인버터 → 바이폴라 푸시풀(토템폴) 출력
                 ┌────────┐
   V_IN ──CMOS──┤ Q3 (NPN up)   VDD
                 └────────┘       |
                    +      R┐    ┘
                 ┌────────┐  o───V_OUT
                 └ Q4 (NPN dn)   |
                                   GND(전원) bc + 쇼트키 클램프
```

- 장점: **무부하에서 게이트 입력 정전용량이 낮아 빠르고, 대용량 부하(버스, 전송선)를 빠르게 구동** – 특히 γ단입력 용량이 BJT 고이득으로 문자열 구동.
- 단점: 공정 복잡(CMOS+BJT 동시 제작), 정적 전력 증가.
- 응용: 1980~90년대 워크스테이션 CPU(SPARC, Alpha), 74BCT 시리즈 (BiCMOS TTL-호환).

## 6. 공정 스케일링과 최신 트랜지스터

### 6.1 고전 스케일링 법칙 (Demard, 1974)

| 파라미터 | Scaling factor (정전압 스케일) |
|---|---|
| $W, L, t_{ox}$ | 1/S |
| $V_{DD}, V_T$ | 1/S |
| 동작 주파수 $f$ | S |
| 구동 전류 | 1/S |
| 단위 면적 전력 | 1 (일정) |
| 패키지 전력 | 1/S² (감소!) |

- 이상: 축소하면 **전력밀도 일정 + 속도 향상**. 2005년경 크게 무너짐 → **Demard 스케일링의 종말**.

### 6.2 무너진 원인: DIBL·누설·전력벽

1. $L$ 축소 → 채널 분리를 VDD로 대신함 → **DIBL**: 드레인 전계가 소스 배리어를 낮춤 → 서브문턱 누설 급증.
2. **전력 벽 (power wall)**: $P \propto \alpha C V^2 f$인데 $f \uparrow, C \uparrow$ (점점 캐시/코어 증가) → 발열 한계 도달. → **멀티코어 전환 + Clock gating.**
3. **신뢰성**: 게이트 산화막이 1nm대 → 직접 터널링 누설 $I_{gate}$ 폭증.

### 6.3 FinFET (3차원 트랜지스터)

- 구조: 게이트가 실리콘 "핀(fin)" 3면을 감쌈(트라이게이트).

```
   G   G   G
  ┌───┐┌───┐ g/SiO2 +
  │   ││   │  Hk감염
  ─┘Fin┘─┘Fin└──
     W = fin 폭(수 nm), H ≈ 50nm, fin pitch ≈ 80nm
  (채널을 세워 게이트가 3면에서 제어)
```

- **효과**:
  - 게이트 제어 강화 → 서브문턱 스윙 $S \approx 60$~70 mV/dec로 낮음 → 누설 억제
  - **DIBL 감소**, $V_T$ 변동(RVT) 감소
  - 구동(특짓)은 동일 폭 대비 증가
- 파라미터 예시 (7nm 공정): fin 폭 ~5-8nm, HH ~50nm, $V_DD$ ~0.7V~0.9V, fin pitch ~45nm.
- 시리즈: 인텔 22nm(2011) ~ 10/7/5nm, TSMC 16/12/7/5nm, 삼성 10/8/7/5nm 모두 FinFET.

### 6.4 GAA / 나노시트 (Gate-All-Around)

- 구조: 게이트가 채널 **4면 전체(360°)** 를 감쌈. 나노시트(수 nm 두께 Si 층)를 수직 적층(3~4층) → **적층형 트랜지스터**.

```
     G
   ┌──────┐
   │ S1 ──┤  나노시트(채널, 얇은 Si)
   │      │
   │ S2 ──┤  적층
   │      │
   └──────┘
     G
```

- 장점: DIBL·누설 더 감소, $V_T$ 단조성 향상, 배선 밀도 개선(나노시트 간 G) → **후보도 약 30% 향상 (동일전력)**
- 시리즈: 삼성 3nm GAA(2022), TSMC 2nm GAA(nanowire/nanosheet), 인텔 후보(20A) 등.
- 후속 트렌드: **CFET(Complementary FET – N과 P를 수직 적층)**, 2D 재료(몰리브덴 등) 채널, 공기갭 배선, 수백층 3D 적층.

### 6.5 파라미터 비교 (연대별 대표 공정)

| 항목 | 90nm | 32nm | 22nm (FinFET) | 7nm | 3nm (GAA) |
|---|---|---|---|---|---|
| 구조 | planar | planar | FinFET | FinFET | NanoSheet |
| $L_{gate}$ | 40nm | 20nm | 14nm | 10nm | ~8nm |
| $V_{DD}$ | 1.2V | 1.05V | 0.9V | 0.75V | 0.7V |

## 8. 연습문제

**Q1.** 표준 TTL NAND 게이트에서 두 입력이 모두 HIGH일 때 Q1(멀티에미터 트랜지스터)은 어떤 동작 영역(포화/컷오프/역방향 활성/순방향 활성)에 있는지 서술하시오. (정답 키: 역방향 활성 — Q1이 각 에미터를 HIGH로, 콜렉터 쪽을 LOW로 구동)

**Q2.** 74LS 시리즈에서 저장시간(storage time)을 제거하기 위해 사용한 기법 두 가지를 쓰고, 그 원리를 2~3문장으로 설명하시오.

**Q3.** CMOS 인버터에서 $W_P/W_N = 3$으로 설계하는 이유를 수식($V_M$)과 평이한 언어로 각각 설명하시오.

**Q4.** $C_L = 2.4$pF, $V_{DD}=1.2$V, $f=3$GHz, $\alpha=0.3$인 경우 동적 전력 $P_{dyn}$을 계산하시오.

**풀이**: $P = 0.3 \times (2.4\times10^{-12}) \times (1.2)^2 \times 3\times10^9 = 0.3 \times 2.4\times10^{-12} \times 1.44 \times 3\times10^9 \approx 3.11 \text{ mW}$.

**Q5.** Demard 스케일링이 2005년경 종말을 맞은 가장 큰 물리적 원인 두 가지를 쓰시오.

**Q6.** FinFET과 평면 CMOS를 서브문턱 누설, DIBL, 게이트 제어력의 측면에서 비교하시오.

**Q7.** 74HC와 74HCT의 차이(특히 입력 레벨)를 설명하고, 크리스털 오실레이터 회로 등 TTL 레거시 시스템과 연결할 때 어떤 것을 골라야 하는지 이유와 함께 서술하시오.

**Q8.** ECL이 BJT 주제에 전압스윙이 작은 것이 오히려 속도에 유리한 이유를 설명하시오.
