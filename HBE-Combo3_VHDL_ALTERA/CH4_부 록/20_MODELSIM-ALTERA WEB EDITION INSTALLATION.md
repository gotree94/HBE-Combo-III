# 20. MODELSIM-ALTERA WEB EDITION INSTALLATION

> 출처 : 「HBE-Combo III 로 배우는 VHDL을 이용한 디지털 회로 설계  ALTERA V1 최종 20080616-p371」 4장 「20. MODELSIM-ALTERA WEB EDITION INSTALLATION」 (원본 도서 349~358쪽)

CH4 부 록ModelSim 소프트웨어는 유명한 시뮬레이션 프로그램 중 하나이다. 이 중 ModelSim-AlteraWeb Edition은 Altera사에서 Quartus II 프로그램과 연동하기 위하여 Mentor사와 계약을 맺고ModelSim의 Altera Edition을 무료로 사용할 수 있도록 제공하고 있다.이 장에서는 이 ModelSim 소프트웨어를 설치하는 방법에 대하여 설명하고 있다.

## 20.1.  ModelSim-Altera Web Edition Download

ModelSim-Altera Web Edition 소프트웨어는 Mentor사의 홈페이지가 아닌 Altera사의 홈페이지를 통해서 다운로드 받아야 한다. 아래의 순서로 Altera사의 홈페이지에 접속하여 소프트웨어를 다운로드 받을 수 있다.z아래와 같이 ALTERA사의 홈페이지(http://www.altera.com)에 접속을 한다.ModelSim-AlteraInstallationz오른쪽 상단의 Download를 클릭한다.zDownload Center의 창에서 아래 그림과 같이 Quartus II Web Edition의 Software를선택한다.CH4 부 록z아래 그림과 같이 ModelSim-Altera Web Edition의 Windows 버전을 Download 한다.zAccount Sign 창에서 등록하거나, 아래의 그림과 같이 Get One Time Access버튼을 눌러,해당하는 정보들 등록을 하면 ModelSim-Altera Web Edition을 다운로드 받을 수 있다.CH4 부 록

## 20.2.  프로그램 설치

아래의 순서로 ModelSim-Altera Web Edition 프로그램을 설치한다.z다운로드 받은 ModelSim-Altera Web Edition 설치 프로그램(80_modelsim_ae_free.exe)을실행시킨다.z아래 그림과 같이 설치 창에서 Next 버튼을 누른다.z아래 그림의 License Agreement 창에서 Yes 버튼을 누른다.z아래 그림과 같이 프로그램 설치 폴더를 설정하고, Next 버튼을 누른다.CH4 부 록z아래그림과 같이 프로그램 폴더를 설정하고, Next 버튼을 누른다.z아래 그림과 같이 Install 요약 정보를 확인한 후 Next 버튼을 누른다.z위에서 Next 버튼을 누르면 아래 그림과 같이 프로그램의 설치가 시작된다.z프로그램의 설치가 끝나면 Hardware Security Key Driver를 설치할 것이냐는 메시지가나타나는데, Ethernet address를 이용한 License를 사용하기 때문에 아래 그림과 같이“아니오” 버튼을 선택한다.z아래 그림에서 Finish 버튼을 눌러 프로그램의 설치를 완료한다.CH4 부 록

## 20.3.  License 설정

ModelSim-Altera Web Edition의 License도 프로그램과 마찬가지로 Altera사의 사이트에서 신청하여 받을 수 있다. 여기에서는 앞의 “19. Quartus II Installation” 장의 “19.4. License 설정”에서 License 설정을 하였다면, ModelSim-Altera Web Edition의 License는 설정하지 않아도 프로그램의 동작이 잘 이루어진다.
