# 11. 레지스터

## 11.1. 개요

레지스터는 2진 데이터의 저장이 가능한 셀들의 집합이다. 즉 기억소자인 플립플롭으로 구성된 데이터 저장 장소라 할 수 있다.

이 장에서는 레지스터의 여러 가지 형태에 데이터가 저장되는 방법과 저장된 데이터가 레지스터에서 출력되는 방법에 대한 설명을 하고 있다.

## 11.2. 병렬입력/병렬출력 레지스터

여러 비트의 데이터를 동시에 저장할 수 있고, 저장된 모든 2진 데이터를 직접 사용할 수 있는 플립플롭의 모음을 병렬입력/병렬출력 레지스터(Parallel In Parallel Out Register)라고 한다.

아래의 그림은 4비트 병렬입력/병렬출력 레지스터를 블록도로 나타낸 것이다.

4비트 데이터의 입력을 받으며 클럭의 Rising Edge일 때만, D의 데이터 입력이 Q로 출력이 된다. CLR은 데이터를 초기화 시키기 위한 입력 단자로 Low의 데이터가 들어왔을 때, Q의 값이0000으로 초기화 된다.

아래 상태표는 이 동작 상황을 표로 나타낸 것이다.

| CLR | CLK | Q |
|:---:|:---:|:---:|
| 0 | X | 0000 |
| 1 | ↑ | D |


아래의 예제는 위의 블록도를 VHDL으로 구현한 것이다.

```vhdl
-- CH2_4REG.VHD
LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;
USE IEEE.STD_LOGIC_UNSIGNED.ALL;

ENTITY CH2_4REG IS
    PORT (
        CLK, CLRN : IN  STD_LOGIC;
        D         : IN  STD_LOGIC_VECTOR(3 DOWNTO 0);
        Q         : OUT STD_LOGIC_VECTOR(3 DOWNTO 0)
    );
END CH2_4REG;

ARCHITECTURE HB OF CH2_4REG IS
BEGIN
    PROCESS (CLRN, CLK)
    BEGIN
        IF CLRN = '0' THEN
            Q <= "0000";
        ELSIF CLK'EVENT AND CLK = '1' THEN
            Q <= D;
        END IF;
    END PROCESS;
END HB;
```

19 ~ 26라인의 PROCESS 문에 위의 4비트 병렬입력/병렬출력 레지스터가 설계되어 있다. 초기화 신호인 CLRN이 0의 값을 갖고 있을 때 출력 Q의 값이 0000으로 초기화되고, CLRN이 0이아닐 때, 클럭의 Rising Edge에서 D의 입력된 데이터가 Q로 출력이 되도록 구현되어 있다. 앞의 D 플립플롭을 4비트로 비트 확장한 것으로 생각하면 된다.

아래는 이 예제를 시뮬레이션 하기 위한 테스트 벤치 파일과 ModelSim으로 시뮬레이션 한결과이다.

```vhdl
-- TB_CH2_4REG.VHD
LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;
USE IEEE.STD_LOGIC_UNSIGNED.ALL;

ENTITY TB_CH2_4REG IS
END TB_CH2_4REG;

ARCHITECTURE HB OF TB_CH2_4REG IS
    COMPONENT CH2_4REG
        PORT (
            CLK, CLRN : IN  STD_LOGIC;
            D         : IN  STD_LOGIC_VECTOR(3 DOWNTO 0);
            Q         : OUT STD_LOGIC_VECTOR(3 DOWNTO 0)
        );
    END COMPONENT;

    SIGNAL CLRN : STD_LOGIC := '0';
    SIGNAL CLK  : STD_LOGIC := '0';
    SIGNAL D    : STD_LOGIC_VECTOR(3 DOWNTO 0) := "0000";
    SIGNAL Q    : STD_LOGIC_VECTOR(3 DOWNTO 0) := "0000";
BEGIN
    CLRN <= '0', '1' AFTER 200 NS;

    PROCESS
    BEGIN
        WAIT FOR 50 NS;
        CLK <= NOT CLK;
    END PROCESS;

    D <= "1001", "0110" AFTER 400 NS, "1101" AFTER 500 NS, "0010" AFTER 600 NS;

    U_CH2_4REG : CH2_4REG
        PORT MAP (
            CLK  => CLK,
            CLRN => CLRN,
            D    => D,
            Q    => Q
        );
END HB;
```

이 테스트 벤치 파일에서 27라인은 CLRN의 데이터를 처음 값은 0으로 200ns 후에는 1로 바뀌도록 구성한 구문이다. 35라인은 D 신호 라인에 전달해 줄 데이터를 생성하는 구문이다.아래의 시뮬레이션 결과에서 CLRN이 0일 때 모든 Q의 데이터는 0000으로 초기화되고, CLRN이 1이고 클럭의 Rising Edge일 때, D의 입력이 Q로 출력되는 것을 확인할 수 있다.

위의 로직을 HBE-Combo III에서 동작시키기 위해서는 아래 표와 같이 핀 설정을 해 주어야한다.입력 데이터 CLK은 Button SW1와 연결하고 CLRN은 FPGA_RESET과 연결한다. 그리고,  4비트데이터 입력 D는 BUS SW1 ~ 4를 설정한다. 출력 결과 Q는 각각 LED1 ~ 4을 설정하여 LED를 통해서 결과를 확인할 수 있도록 한다.

| 포트 이름 | 핀 번호 | 하드웨어 설명 | 포트 이름 | 핀 번호 | 하드웨어 설명 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| CLK | V4 | SW1 | Q[3] | AE11 | LED1 |
| CLRN | C5 | FPGA_RESET | Q[2] | AE10 | LED2 |
| D[3] | U5 | BUS SW1 | Q[1] | AF9 | LED3 |
| D[2] | U4 | BUS SW2 | Q[0] | AF8 | LED4 |
| D[1] | V6 | BUS SW3 |  |  |  |
| D[0] | V5 | BUS SW4 |  |  |  |

핀 설정 후 컴파일 한다. HBE-Combo III 장비에 다운로딩 하고, 상태 천이도의 동작대로 동작이 되는지를 확인해 보자.

## 11.3. 직렬입력/직렬출력 레지스터

직렬입력/직렬출력 레지스터는 한 번에 한 비트씩 데이터가 저장된다는 점의 차이를 제외하고,병렬입력/병렬출력 레지스터와 구조가 거의 같다. 직렬입력/직렬출력 레지스터는 매 클럭이발생할 때마다 데이터는 한 비트씩 플립플롭들을 통과하여 레지스터의 다른 쪽 끝으로 이동한다. 계속 클럭이 발생하면, 데이터는 처음 저장되는 순서대로 한번에 한 비트씩 레지스터를빠져나간다.

아래는 4비트 직렬입력/직렬출력 레지스터의 블록도와 이것을 논리 회로로 구현한 것이다.

DIN에서 입력된 데이터가 클럭의 Rising Edge에서 첫 번째 플립플롭의 출력 Q0으로 출력되어다음 플립플롭의 입력에 연결된다. 이 데이터는 클럭의 다음 Rising Edge에서 두 번째 플립플롭의 출력 Q1에 출력된다. 같은 방법으로 클럭의 Rising Edge에 반응하여 데이터가 전달되며위의 회로에서는 총 4번의 클럭이 발생한 후에 DIN의 데이터가 Q로 출력 된다. CLRN의 신호는 이 값이 0일 때, 모든 레지스터 (플립플롭)의 값이 0으로 초기화 하는 역할을 한다.

아래는 4비트 직렬입력/직렬출력 레지스터에 임의의 데이터와 클럭을 인가하였을 때의 동작을나타낸다.

CLRN이 0의 데이터를 갖고 있을 때 모든 레지스터는 초기화가 되고, CLRN이 1일 때 클럭이발생하면 DIN으로 들어온 데이터가 내부 레지스터에 하나씩 저장이 되어 4번째 클럭에서 외부로 출력되는 것을 확인할 수 있다. 아래 파형에서 (Q0), (Q1), (Q2)의 파형은 논리 회로 내부에서 동작의 이해를 돕고자 같이 그려놓았다. 4비트 직렬입력/직렬출력 레지스터의 DIN 입력에대한 실제 출력 파형은 Q이다.

위의 4비트 직렬입력/직렬출력 레지스터는 아래와 같이 VHDL로 구현할 수 있다.

```vhdl
-- CH2_4SISO.VHD
LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;
USE IEEE.STD_LOGIC_UNSIGNED.ALL;

ENTITY CH2_4SISO IS
    PORT (
        CLK, CLRN : IN  STD_LOGIC;
        DIN       : IN  STD_LOGIC;
        Q         : OUT STD_LOGIC
    );
END CH2_4SISO;

ARCHITECTURE HB OF CH2_4SISO IS
    SIGNAL REG : STD_LOGIC_VECTOR(3 DOWNTO 0);
BEGIN
    PROCESS (CLRN, CLK)
    BEGIN
        IF CLRN = '0' THEN
            REG <= "0000";
        ELSIF CLK'EVENT AND CLK = '1' THEN
            REG <= REG(2 DOWNTO 0) & DIN;
        END IF;
    END PROCESS;

    Q <= REG(3);
END HB;
```

사실 26라인의 REG <= REG(2 DOWNTO 0) & DIN;의 구문이 4비트 직렬입력/직렬출력 레지스터의 내부 모든 회로를 나타낸다. 이 로직을 살펴보면 한 비트의 출력 결과만 갖는 다는 점을제외하고는 4비트 시프트 레지스터와 같은 것을 알 수 있다.

아래는 이 예제를 시뮬레이션 하기 위한 테스트 벤치 파일과 ModelSim 으로 시뮬레이션 한결과이다.

```vhdl

    COMPONENT CH2_4SISO
        PORT (
            CLK, CLRN : IN  STD_LOGIC;
            DIN       : IN  STD_LOGIC;
            Q         : OUT STD_LOGIC
        );
    END COMPONENT;

    SIGNAL CLRN : STD_LOGIC := '0';
    SIGNAL CLK  : STD_LOGIC := '0';
```

위의 로직을 HBE-Combo III에서 동작시키기 위해서는 아래 표와 같이 핀 설정을 해 주어야한다.

입력 데이터 CLK와 DIN에는 각각 Button SW1, SW2을 설정하고, CLRN에는 FPGA_RESET을 설정한다. 출력 결과 Q는 LED1을 설정하여 결과를 LED를 통해서 확인할 수 있도록 한다.

## 11.4. 병렬입력/직렬출력 레지스터

병렬입력/직렬출력 레지스터는 N비트의 병렬 데이터의 입력을 받아, N개의 클럭 동안 입력받은 병렬 데이터를 직렬 데이터로 변환하여 출력하는 레지스터를 말한다. 이것은 아래 그림과 같이 블록도로 나타낼 수 있다. SH/LDN 신호는 D 데이터의 입력을 받기 위한 신호로 이값에 0이 들어왔을 때, D 데이터 입력을 받으며 1이 되면 클럭의 Rising Edge에 데이터의 시프트가 이루어져 입력 받은 N비트의 D데이터가 하위 비트에서부터 상위 비트의 순서대로(D0,D1, … , DN-1, DN) Q에 출력된다.

아래 파형은 4 비트 병렬입력/직렬출력 레지스터에 임의의 데이터를 넣어 동작하는 결과이다.

SH_LDN의 신호가 발생하면 4비트 레지스터에 값이 설정되고, 그 후 클럭의 Rising Edge에 하나씩 데이터가 시프트 되어 출력되는 것을 볼 수 있다. 클럭이 4번 발생하여 모든 데이터가출력하면 다음 데이터를 불러 들어올 때까지 출력 값은 0의 값이 나온다.

아래는 위의 4비트 병렬입력/직렬출력 레지스터를 VHDL로 구현한 것이다.

```vhdl
-- CH2_4PISO.VHD
LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;
USE IEEE.STD_LOGIC_UNSIGNED.ALL;

ENTITY CH2_4PISO IS
    PORT (
        CLK    : IN  STD_LOGIC;
        SH_LDN : IN  STD_LOGIC;
        D      : IN  STD_LOGIC_VECTOR(3 DOWNTO 0);
        Q      : OUT STD_LOGIC
    );
END CH2_4PISO;

ARCHITECTURE HB OF CH2_4PISO IS
    SIGNAL REG : STD_LOGIC_VECTOR(3 DOWNTO 0);
BEGIN
    PROCESS (SH_LDN, CLK)
    BEGIN
        IF SH_LDN = '0' THEN
            REG <= D;
        ELSIF CLK'EVENT AND CLK = '1' THEN
            REG <= REG(2 DOWNTO 0) & '0';
        END IF;
    END PROCESS;

    Q <= REG(3);
END HB;
```

아래는 이 예제를 시뮬레이션 하기 위한 테스트 벤치 파일과 ModelSim으로 시뮬레이션 한결과이다.

## 11.5. 직렬입력/병렬출력 레지스터

직렬입력/병렬출력 레지스터는 위의 병렬입력/직렬출력 레지스터와는 정반대의 동작을 수행한다. 즉 직렬 데이터의 입력을 받아 병렬의 데이터를 출력하는 기능을 한다. N비트의 직렬입력/병렬출력 레지스터는 N개의 클럭이 발생하는 데이터에 의해서 병렬데이터가 결정된다. 이것은 시프트 레지스터와 같은 동작을 한다.

아래는 4비트 직렬입력/병렬출력 레지스터이다. CLRN의 입력이 0일 때 모든 레지스터의 값이0으로 초기화 되며, 클럭이 발생할 때마다 DIN의 값이 Q0로 넘겨지고, Q0의 값이 Q1으로 넘겨지는 방법으로 하여 4번의 클럭이 발생하면 4비트의 데이터가 완성된다.

아래 상태 표는 DIN을 1로 고정하였다고 가정하고, 클럭을 발생하였을 때의 그 출력 결과를보여주고 있다.

CLRNCLKDINQ0Q1Q2Q30XX0000000000

아래에 설계된 VHDL로직은 위의 직렬 입력/병렬 출력 레지스터를 설계한 것이다.

```vhdl
-- CH2_4SIPO.VHD
LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;

ENTITY CH2_4SIPO IS
    PORT (
        RESETN  : IN     STD_LOGIC;
        DATA_IN : IN     STD_LOGIC;
        CLK     : IN     STD_LOGIC;
        Q       : BUFFER STD_LOGIC_VECTOR(3 DOWNTO 0)
    );
END CH2_4SIPO;

ARCHITECTURE HB OF CH2_4SIPO IS
BEGIN
    PROCESS (RESETN, CLK)
    BEGIN
        IF RESETN = '0' THEN
            Q <= "0000";
        ELSIF CLK'EVENT AND CLK = '1' THEN
            Q(3) <= DATA_IN;
            Q(2) <= Q(3);
            Q(1) <= Q(2);
            Q(0) <= Q(1);
        END IF;
    END PROCESS;
END HB;
```

위의 로직에서 18~26라인의 구문은 데이터를 하나씩 오른쪽으로 이동시키기 위한 구문이다.

STD_LOGIC과 같은 SIGNAL Type의 변수는 값의 업데이트가 프로세서 문이 끝나는 시점에서이루어지기 때문에 위와 같이 설계되었더라도, 클럭이 발생하였을 때 모든 값이 같아 지지 않고 하나씩 값이 바뀐다.

또, 10라인에서 출력 Q를 OUT이 아닌 BUFFER로 선언한 이유는 OUT의 경우 출력만을 위한포트이기 때문에 21~24라인과 같은 구문처럼 사용할 수 없다. 그래서 BUFFER로 선언하여 사용하였다.

아래는 이 예제를 시뮬레이션 하기 위한 테스트 벤치 파일과 ModelSim으로 시뮬레이션 한결과이다.

```vhdl
-- TB_CH2_4SIPO.VHD
LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;
USE IEEE.STD_LOGIC_UNSIGNED.ALL;

ENTITY TB_CH2_4SIPO IS
END TB_CH2_4SIPO;

ARCHITECTURE HB OF TB_CH2_4SIPO IS
    COMPONENT CH2_4SIPO
        PORT (
            RESETN  : IN     STD_LOGIC;
            DATA_IN : IN     STD_LOGIC;
            CLK     : IN     STD_LOGIC;
            Q       : BUFFER STD_LOGIC_VECTOR(3 DOWNTO 0)
        );
    END COMPONENT;

    SIGNAL RESETN  : STD_LOGIC := '0';
    SIGNAL DATA_IN : STD_LOGIC := '0';
    SIGNAL CLK     : STD_LOGIC := '0';
    SIGNAL Q       : STD_LOGIC_VECTOR(3 DOWNTO 0) := "0000";
BEGIN
    RESETN  <= '0', '1' AFTER 10 NS;
    DATA_IN <= '0', '1' AFTER 100 NS, '0' AFTER 200 NS, '1' AFTER 400 NS, '0' AFTER 600 NS;

    PROCESS
    BEGIN
        WAIT FOR 50 NS;
        CLK <= NOT CLK;
    END PROCESS;

    U_CH2_4SIPO : CH2_4SIPO
        PORT MAP (
            RESETN  => RESETN,
            DATA_IN => DATA_IN,
            CLK     => CLK,
            Q       => Q
        );
END HB;
```

아래의 시뮬레이션 결과에서 DATA_IN의 데이터는 클럭에 의해서 1비트씩 시프트 되어 출력되는 것을 확인할 수 있다. 총 4번의 클럭이 발생하였을 때, 즉 4개의 데이터가 들어와 완전한4비트의 데이터가 만들어진다.

위의 로직을 HBE-Combo III에서 동작시키기 위해서는 아래 표와 같이 핀 설정을 해 주어야한다.

입력 데이터 DATA_IN과 CLK에는 Button SW1과 SW2가 설정되고, 출력 결과를 나타내는 Q에는 각각 LED1~4을 통해 확인할 수 있도록 핀을 설정한다.

| 포트 이름 | 핀 번호 | 하드웨어 설명 | 포트 이름 | 핀 번호 | 하드웨어 설명 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| RESETN | C5 | FPGA_RESET | Q[2] | AE10 | LED2 |
| DATA_IN | V3 | SW1 | Q[1] | AF9 | LED3 |
| CLK | V4 | SW2 | Q[0] | AF8 | LED4 |
| Q[3] | AE11 | LED1 |  |  |  |

핀 설정 후 컴파일 한다.HBE-Combo III 장비에 다운로딩 하고, 그 결과를 확인하여 시프트 레지스터에 대해 이해해 보자.
