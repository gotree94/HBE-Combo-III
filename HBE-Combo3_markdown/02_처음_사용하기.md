# 2. 처음 사용하기

본 장비는 사용하기 위해서는 사용 환경을 만들어 주셔야 합니다. 이 작업은 장비에 대한 전원 및 케이블 연결 상태를 먼저 확인 해 보셔야 하고, 다음으로 사용자가 사용 하려는 PC의 작업 환경도 구축해 놓아야 합니다. 먼저 장비를 확인해 보시면 오른 쪽에 장비를 사용하기 위한 케이블 수납 공간이 있 습니다. 여기에서 장비에 전원을 연결하기 위한 전원 케이블과 다운로드 케이블을 장 비에 연결해 주시기 바랍니다. 아래 그림을 통해 연결 방법을 확인해 보시기 바랍니다. 위와 같이 장비에 연결이 되어 있다면 장비의 전원을 켜고 동작 상태를 확인해 보시 기 바랍니다. 장비에서는 출고 시 데모 프로그램이 FPGA 모듈에 들어 있기 때문에 전원을 켬과 동시에 FPGA 모듈의 Configuration ROM에서 FPGA 디바이스로 데이터 를 넘겨주어 장비의 데모 프로그램이 동작을 하게 됩니다. 이렇게 장비에서 케이블 연결과 장비의 동작 상태를 확인하였으면 PC의 환경을 설정 해 주어야 합니다. FPGA 모듈을 사용하기 위해서는 각 디바이스 벤더에서 제공하는 설계 툴을 다운 받 아 설치 해 주셔야 합니다. 이 툴은 ALTERA 및 XILINX사의 홈페이지에서 무료 웹 버전을 다운받아 사용할 수 있습니다.
## 2.1 Altera Quartus II

**1)** 소프트웨어 다운로드

여기서는 알테라 홈페이지에서 Quartus II를 다운 받는 방법을 설명하도록 하겠습니다. Quartus II는 알테라의 PLD 디바이스를 제어하기 위해 사용하는 툴로써 알테라 홈페 이지에서 무료 웹 버전을 다운받아 사용이 가능합니다. 또한 이 툴은 시간이 지남에 따라 버전이 업로드 되기 때문에 아래에 설명한 다운로드 이미지가 좀 다를 수 있으 니 이 점 유념하기 바랍니다. 이제부터 각 단계별 다운로드 과정을 진행하도록 하겠습 니다. ▪ 첫 번째 단계로는 인터넷이 연결된 PC를 통해 알테라 홈페이로 들어갑니다. 주소는 http://www.altera.com/ 입니다. 이렇게 진행을 하면 다음과 같은 화면이 됩니다.
> **그림 2-1** · ALTERA Home

▪ 여기에서 상단의 ‘Download’를 클릭하여 다운로드 센터로 들어갑니다.
> **그림 2-2** · Download Center

▪ 이 화면에서 상단의 Quartus II Software Downloads 라는 표를 통해 Quartus II Web Edition을 다운 받을 수 있습니다. 여기에서는 현재 V7.2 SP3을 다운 받을 수 있 고 이 버전을 향상 될 수 있습니다. 표 안에서 웹 버전의 ‘Software’ 버튼을 클릭합 니다.
> **그림 2-3** · Select Software

▪ 다음 창에서는 Quartus II의 설계 툴 중 설치하려는 것을 선택하게 됩니다. 여기에서는 Quartus II Web Edition을 다운로드 하기 때문에 맨 윗칸의 Download를 선택합니다.
> **그림 2-4** · Select Quartus II Tools

▪ 현재 사용자의 정보를 입력합니다. 알테라 홈페이지에 미리 등록이 되어 있으면 User Name와 Password를 입력하면 되고, 이번 한 번만 다운로드 하시려면, Get One- Time Access에 체크를 한 뒤 다음 과정으로 진행 하시면 됩니다.
> **그림 2-5** · Sign-In

▪ 여기서는 사용자의 정보를 입력하는 곳입니다. 여기에서 주의할 점은 이 메일 주소를 정확하게 작성해 주셔야 합니다. Qaurtus II 툴을 받고 라인센스 파일을 받을 때 메일 로 DAT 파일이 전달 되는데 필요한 주소입니다. 따라서 정확한 메일 주소를 작성해 주 셔야 라인센스 파일을 받을 수 있습니다.
> **그림 2-6** · Registration

▪ 이렇게 정보를 입력하면 다음 화면에서 Quartus II의 프로그램을 다운받을 수 있는 창 으로 이동하게 됩니다. 이때 전용 다운로드 매니저를 설치한 뒤 다운받을 지 결정을 하 게 되는데, 이것을 설치한 다음 진행을 하거나 화면 아래에 ‘Click to Download Your File Now’를 클릭한 다음 진행을 하시면 됩니다.
> **그림 2-7** · Downloading

▪ 위의 설명과 아래 메시지를 클릭하면 아래 그림과 같은 창이 뜨게 되고 사용자가 PC의 폴더를 지정하여 저장을 하면 됩니다.
> **그림 2-8** · File Download

▪ 위와 같은 방법으로 파일을 다운 받으면 이제 툴의 동작을 위한 라이센스 파일도 다운 받아야 합니다. 이전에 다움받은 알테라 홈페이지 작업 창을 닫지 말고 Quick links => License나 상단의 Licensing를 클릭합니다.
> **그림 2-9** · License Download

▪ 알테라의 Quartus II를 사용하기 위해서는 툴을 설치한 다음 라이센스 파일을 등록해 주어야 합니다. 만약 툴만 설치를 한다면 컴파일 과정에 라이센스 파일이 없어 컴파일 이 진행되지 않고 종료되게 됩니다. 라인센스 파일을 알테라 홈페이지에서 무료로 다운 받을 수 있으며 유효 기간이 끝난 다음에는 다시 받아서 등록해 주시면 됩니다. 다음 창에서는 라인센스 작업을 위한 첫 번째 단계인 화면을 보여주고 있습니다. 여기에서 노란색으로 표시한 곳의 ‘Get license’를 클릭하여 다음 단계로 진행합니다.
> **그림 2-10** · Altera Licensing

▪ 여기에서는 알테라 홈페이지에서 지원하는 여러 라인센스 중 Quartus II에 대한 라이센 스를 선택하시면 됩니다. 화면 상단의 노란색 표시 부분을 클릭하여 다음 진행 단계로 진행합니다.
> **그림 2-11** · Get My Altera License

▪ 이 단계에서는 이전에 프로그램 다운로드 시 작업한 정보를 그대로 가지고 있으므로 Personal Information에는 정보가 들어 있습니다. 따라서 이 창에서는 PC의 Network Interface Card 번호를 등록해 주어야 합니다. 이 카드 번호는 도스 창에서 “ipconfig /all” 명령어를 통해 확인할 수 있습니다. 이 번호는 라이센스 파일을 만들 때 각 컴퓨 터의 고유 네트워크 번호를 통해 생성함으로 정확하게 기입해 주어야 합니다.
> **그림 2-12** · Registration Information

▪ 이 단계에서는 툴을 다운 받는 사람의 설문을 위한 단계입니다. 총 10 문항에 대한 질 물이 있으며 해당되는 곳에 체크를 한 뒤 다음 단계로 진행 하시면 됩니다.
> **그림 2-13** · Licensing Survey

▪ 이렇게 모두 작성을 마치면 사전에 등록된 메일 주소로 라이센스 파일이 전달이 됩니다. 이 파일은 바로 전달이 될 수 있고 최대 12 시간이 걸릴 수 있습니다. 만약 전달이 안 되면 스펨 메일 폴더나 라이센스 다운 작업을 다시 진행해 보시기 바랍니다.
> **그림 2-14** · Licensing Requrst Completed

**2)** 소프트웨어 설치

▪ 이렇게 설계 Quartus II 및 라이센스 다운로드 작업을 마치게 되면, 툴을 먼저 실행하 여 설치를 해 줍니다. 설치가 끝나고 Quartus II를 실행하면 아래 그림과 같이 화면이 보이게 됩니다. 이 창에서 Quartus II를 선택해 주시면 됩니다. 또한 다음 단계에서 나 오는 창은 현재 라이센스가 등록이 되어 있지 않아 나타나는 창입니다. 사전에 메일로 받은 라이센스 파일을 Quartus II가 설치된 폴더로 저장 한 다음, Licensing Error 창 에서 마지막 것을 체크하고 다음 단계로 진행합니다.
> **그림 2-15** · Licensing Error

▪ 이 단계에서는 메일로 받은 라이센스 파일을 Quartus II에 등록해 주는 단계입니다. 다 름 그림의 License file의 탐색 버튼을 통해 라이센스를 저장한 폴더를 검색하여 저장 된 라이센스 파일을 찾아서 등록해 줍니다. 이렇게 하면 그림과 같이 Current License 의 License Type이 Web Edition으로 변경이 됩니다. 이 때 OK 버튼을 눌러 라이센 스 등록 작업을 마치면 됩니다.
> **그림 2-16** · License Setup

▪ 위와 같은 작업을 마치면 ALTERA 디바이스를 사용하기 위한 PC 환경의 설정 작업이 모두 끝났습니다. 따라서 장비를 통한 제어 실험 환경이 구축된 상태입니다.
## 2.2 XILINX ISE

**1)** 소프트웨어 다운로드

▪ 자일링스 모듈을 사용하기 위해서는 XILINX에서 지원하는 설계 소프트웨어인 ISE를 이 용하여 설계해 주어야 합니다. 이는 XILINX 홈페이지에서 무료로 다운받아 사용할 수 있습니다. http://www.xilinx.com/를 클릭하여 자일링스 홈페이지에 들어갑니다. 여기 에서 상단에 Downloads를 클릭하여 Xilinx 다운로드 센터로 들어갑니다.
> **그림 2-17** · Xilinx Home

▪ 자일링스 다운로드 센터에서는 자일링스 디바이스를 사용하기 위한 여러 개의 툴을 지 원해 주고 있습니다. 여기에서 ISE WebPACK의 다운로드를 클릭하여 다음 단계로 진 행합니다.
> **그림 2-18** · Xilinx Download Center

▪ 여기에서는 사용자 등록을 하는 창입니다. 사전에 등록이 되어 있으면, ID 및 Password를 입력하여 다음 단계로 진행하면 되고, 등록이 되어 있지 않으면 Create Account를 통해 사용자 등록을 해 주어야 합니다. 사용자 등록은 몇 단계를 통해 ID 및 Password, 메일 주소 등을 기입하여 등록을 하게 됩니다.
> **그림 2-19** · Sign in to Xilinx

▪ 사전에 저장된 ID 및 Password를 기입하여 입력하면 사전에 저장된 정보가 다음 창에
서 보여집니다. 여기에서는 이러한 정보를 다시 한번 확인 할 수 있도록 보여주고 있습 니다. 또한 메일 주소 이외에는 수정을 할 수 있습니다.
> **그림 2-20** · Xilinx Electronic Fulfillment

▪ 현재 창에서는 다운로드 하려는 프로그램을 확인하고 다시 한번 선택할 수 있습니다. 현재 ISW WebPACK에 대한 다운로드를 진행 중이라는 것을 보여주고 있으며, 다른 응 용 툴에 대한 선택도 이 창에서 추가 할 수 있습니다.
> **그림 2-21** · Select Product

▪ 이 창에서는 다운로드 하기 위한 마지막 창으로써 아래 그림에서 볼 수 있듯이 Download를 클릭하여 다운로드 하게 됩니다. 창에서 오른쪽의 Download Files Individually를 클릭하면 ISE WebPACK의 다운로드 할 수 있는 창이 활성화 됩니다. 또한 다운로드 시 창에서 보이는 Registration ID를 기입해 두셔야 합니다. 이 ID는 프 로그램 설치 시 이용되기 때문에 반드시 저장해 두시기 바랍니다.
> **그림 2-22** · Download Product

**2)** 소프트웨어 설치

파일의 다운을 마치면 저장된 폴더로 이동하여 압축을 풀어 주셔야 합니다. 다운 시 파일은 tar 압축 파일로 저장이 되면 하위 폴더에 압축을 풀어 주시면 됩니다. 이렇게 압축을 풀면, Setup이라는 실행 파일이 생성되며 이 파일을 실행하여 프로그램 설치를 시작해 주시면 됩니다. ▪ 파일을 실행하면 다음의 그림과 같이 프로그램 설치 시작 화면이 보여집니다. 여기에서 는 소프트웨어 설치 정보를 보여주며, Next 버튼을 통해 다음 단계로 진행 하시면 됩니 다.
> **그림 2-23** · Software Installation – Welcome

▪ 이 창에서는 사용자의 Registration ID를 입력하는 단계로 다운 받을 시 제공하는 각 사용자의 ID를 입력 해 주시면 됩니다. 만약 ID가 없다면 Product Registration and Download Site 버튼을 통해 Xilinx 홈페이지에서 확인해서 입력해 주시면 됩니다. 입 력이 마치면 다음 단계로 진행 합니다.
> **그림 2-24** · Software Installation - Enter Registration ID

▪ 여기에서는 다운로드 하려는 것을 다시 한번 확인합니다. 확인 뒤 이상이 없으면 Next 버튼을 눌러 다음 단계로 진행 합니다.
> **그림 2-25** · Software Installation - Select Products to Install

▪ 이 창에서는 라이센스를 등록하는 창으로 총 2개의 창으로 이루어 져 있습니다. 두 창 에서 아래에 ‘I accept the terms of this software license’를 체크한 뒤 다음 단 계로 진행합니다.
> **그림 2-26** · Software Installation - Accept Software License

▪ 이 단계에서는 소프트웨어를 설치하려는 폴더를 지정하는 장소입니다. 여기에서는 버전 에 따라 폴더가 나뉘어져 설치를 하게 됩니다. 사용자가 다른 폴더에 설치하려고 하면 이 단계에서 폴더를 지정해 주시면 됩니다.
> **그림 2-27** · Software Installation - Select Destination Directory

▪ 이 단계에서는 설치하려는 툴의 옵션을 지정할 수 있는 단계입니다. 따라서 사용자가 필요한 것만 지정하여 설치를 해 줄 수 있습니다.
> **그림 2-28** · Software Installation - Select Installation Options

이렇게 선택을 하면 소프트웨어가 설치를 진행합니다. 설치가 끝나면 프로그램을 실행 하여 장비를 제어할 수 있습니다. 이 소프트웨어는 Quartus II와는 달리 따로 라이센 스 설정 단계가 필요 없습니다.
## 2.3 보드 설정

▪ 제품은 출고 시 기본 모듈이 장착된 상태로 출고가 됩니다. 또한 장비의 구동에 필요한 각종 케이 블은 케이블 수납함에 모두 포함되어 있습니다. 모듈은 모두 전용 소켓으로 구성이 되어 있으며, 탈 장착이 가능합니다. 또한 모듈을 반대로 장착 시 커넥터가 파손될 수 있으므로 주의해 주시기 바랍니다. ▪ 확장 모듈의 장착은 왼쪽에 커넥터가 장착되어 있는 형태로 구성되어 있습니다. 따라서 보드의 왼 쪽을 잡은 상태에서 보드를 탈 장착 해 주셔야 합니다. 보드의 탈 장착시 오른쪽에 있는 나사를 통해 보드를 장비에 고정할 수 있습니다. ▪ 제품에 포함되어 있는 전원 케이블을 제품의 왼쪽 측면이 있는 전원 연결 포트에 연결합니다. 전 원연결 포트에 스위치가 꺼져 있는지 확인하신 후 전원 케이블을 전원 플러그에 연결합니다. LPT 용 케이블을 PC의 LPT (프린트) 포트에 연결하고 다른 한쪽은 각 디바이스 모듈에 맞는 다운로드 전용 케이블과 연결해 줍니다. 이러한 다운로드 케이블은 디바이스 모듈의 JTAG 포트와 연결합니 다.
▪ 보드 메인 전원 스위치를 on하여 Base 보드와 FPGA 모듈의 전원 LED에 불이 제대로 들어오는지 확인하고 전원 LED에 불이 들어오지 않을 경우 전원 케이블이 제대로 연결되었는지 또는 제품에 서 쇼트 (단락)된 부분이 없는지 확인하기 바랍니다. ▪ 전원이 정상적으로 들어 올 경우 JTAG 커넥터를 통해 설계 소프트웨어의 프로그램 창을 이용하여 디바이스를 검색할 수 있습니다. Altera Quartus II에서는 Programmer에서 Auto Detect 버튼을 클릭하면 JTAG 커넥터와 연결된 Altera 디바이스 (EP2C70F672)가 보이게 됩니다. Xilinx ISE에서 iMPACT 에서 Initialize Chain으로 디바이스 검색을 하면, 연결된 디바이스 (XCF08, XC3SD1800FGG676)가 화면상에 보이게 됩니다. ▪ 이렇게 디바이스 검색을 통한 연결 상태 및 전원을 확인을 해 보고 장비에 직접 다운로드 하여 미 리 설계된 설계 소스를 이용하여 장비의 동작을 확인해 볼 수 있습니다. 툴의 다운로드 창을 이용 하여 장비에 있는 디바이스에 다운로드 합니다. 다운로드가 완료되면 장비가 사용자가 설계한 상 태대로 동작을 하게 됩니다. 이 때 동작의 이상이 있거나 다운이 정상적으로 이루어 지지 않을 경 우, 모듈의 전원이나 케이블의 연결 상태를 확인하고 다시 다운해 보기 바랍니다.
