# 3.16 UART

[← 목차로 돌아가기](03_제품_사용하기.md)

**1)** 구성

본 제품에는 PC의 RS232(시리얼)포트와 연결하여 시리얼 데이터 통신을 할 수 있도록 하는 Male타입의 9핀 커넥터를 제공하고 있습니다. 이 장치는 PC에서 장비를 제어할 때 이용할 수 있는 장치로 PC의 하이퍼터미널의 통신 프로그램을 통해 장비와 연동하 여 사용할 수 있습니다.

예를 들어 PC에서 시리얼 포트를 통해 명령어를 장비로 전달하면, 장비의 FPGA 디바 이스가 미리 설계된 소스를 통해 이를 파악하고 해당하는 동작을 하게 됩니다.

**2)** 동작

제품에서 사용된 시리얼 인터페이스용 디바이스는 Analog사의 ADM3202를 사용하였 습니다. 이 디바이스는 최대 460 kbps의 데이터 전송 속도를 가진 디바이스로 최대 2 개의 시리얼 포트를 지원해 주는 디바이스 입니다.

FPGA에서 TTL 레벨로 시리얼 디바이스로 데이터를 보내면 이 디바이스가 시리얼 통 신을 위한 전압 레벨로 변환해 줍니다. 입력은 이와 반대로 입력된 전압 레벨을 FPGA가 인식할 수 있는 TTL 레벨로 변환해 주기 때문에 FPGA 및 PC간의 데이터 통 신이 이루어 지게 됩니다.

시리얼 통신의 이용은 PC등의 주변 환경과 데이터 통신을 장비 내부의 장치를 제어하 거나, 장비에서 얻어지는 센서 등의 값을 다른 장비로 전송하는데 이용할 수 있습니다.

**3)** 회로

회로에서 보는 것과 같이 +3.3V의 전원으로 시리얼 디바이스가 동작을 하게 됩니다. 따라서 회로 구현이 쉬운 장점이 있습니다. 이 디바이스와 9핀 D-SUB 커넥터를 통해 PC와 장비간의 데이터 통신이 이루어 지게 됩니다.

**4)** 핀 구성표

| FPGA Signal | Altera | Xilinx | Description |
|:-------:|:-------:|:-------:|:-------:|
| UART_TXD | F7 | H12 | Transmitter Data Input |
| UART_RXD | H3 | K2 | Transmitter Data Output |
