# 3.15 Step Motor

[← 목차로 돌아가기](03_제품_사용하기.md)

**1)** 구조

장비에서는 모터의 구동 원리 학습을 위해 스테핑 모터 기본으로 제공합니다. 이 모터 는 A, B, /A, /B 4개의 데이터 라인을 가지고 모터 동작을 제어하는 유니폴라 방식의 스텝 모터를 사용하고, 모터로 들어가는 데이터 라인의 주파수 높고 낮음에 따라서 모 터의 회전 속도를 제어 할 수 있습니다.

**2)** 동작

모터 제어를 할 수 있도록 일반적으로 많이 사용하는 스텝 모터가 설치되어 있습니다. 위상 제어를 위해 FPGA I/O가 TR을 통해 연결되어 있으며, 모터의 제어는 여자 방식 에 따라 세가지 방식으로 제어가 가능합니다. 1상 여자, 2상 여자, 1-2상 여자 방식이 있고, 이 중 1-2 여자 방식은 고-분해능의 이점을 기지고 있습니다. 다음의 표에서는 모터를 제어하기 위한 데이터의 흐름을 표로 보여주고 있습니다. 각각의 데이터 라인 에 다음가 같은 표를 순차적으로 인가하여 모터를 회전 시킬 수 있습니다.

▪ 1상 여자

| 구분 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| A | 1 | 0 | 0 | 0 | 1 | 0 | 0 | 0 | 1 |
| B | 0 | 1 | 0 | 0 | 0 | 1 | 0 | 0 | 0 |
| /A | 0 | 0 | 1 | 0 | 0 | 0 | 1 | 0 | 0 |
| /B | 0 | 0 | 0 | 1 | 0 | 0 | 0 | 1 | 0 |

| A | 1 | 0 | 0 | 1 | 1 | 0 | 0 | 1 | 1 |
| B | 1 | 1 | 0 | 0 | 1 | 1 | 0 | 0 | 1 |
| /A | 0 | 1 | 1 | 0 | 0 | 1 | 1 | 0 | 0 |
| /B | 0 | 0 | 1 | 1 | 0 | 0 | 1 | 1 | 0 |

| A | 1 | 1 | 0 | 0 | 0 | 0 | 0 | 1 | 1 |

FPGA에서의 모터 제어는 위 표 중 하나의 여자 방식을 선택하여 모터에 신호를 제공 하여 모터를 동작하게 합니다.

**3)** 회로

회로에서 보는 것과 같이 A, B, /A, /B 4개의 데이터 라인이 FPGA로부터 모터로 입 력되는 모습을 보여주고 있습니다. 모터에서는 FPGA로부터 출력되는 전류가 작기 때 문에 중간에 NPN 트랜지스터를 사용, 전류를 증폭하여 모터로 보내게 됩니다. 따라서 모터에 사용할 수 있는 전류로 증폭이 되어 모터의 동작이 이루어 지게 됩니다.

**4)** 핀 구성표

| FPGA Signal | Altera | Xilinx | Description |
|:-------:|:-------:|:-------:|:-------:|
| STEP_DATA[0] | AA23 | Y22 | Motor Data A |
| STEP_DATA[1] | AB24 | Y25 | Motor Data B |
| STEP_DATA[2] | Y26 | Y21 | Motor Data /A |
| STEP_DATA[3] | AB23 | Y24 | Motor Data /B |
| Motor_Sensor | AA26 | Y26 | Magnetic Sensor |

핀 구성에 있는 Motor_Sensor는 스텝 모터의 구동에 활용할 수 있도록 자기 센서를 두어 모터의 회전을 카운트 하도록 마련하고 있습니다. 이 자기 센서는 모터의 회전 구조물에 자석이 설치 되어 있고 이 자석의 자기를 감지하여 감지된 값을 FPGA로 전 달하게 됩니다. 이 센서는 모터의 구동에 이용할 수 있는 장치로 회전을 감지하여 모 터의 구동에 이용할 수 있도록 구성하고 있습니다.
