# 3.13 SRAM

[← 목차로 돌아가기](03_제품_사용하기.md)

**1)** 구성

본 제품에는 디바이스 내부에서 메모리 영역으로 사용하는 공관 이외에 별도로 256Kx16 Bit를 2개 장착하여, 총 8M bit의 High Speed SRAM을 기본으로 제공하고 있습니다. 이처럼 장비에서는 SRAM을 통한 메모리 영역을 확장해서 사용할 수 있습 니다. 그림에서 SRAM의 구성을 보여주고 있으며, Address를 공통으로 사용하고 데이 터를 32비트로 동작할 수 있도록 구성하고 있습니다. SRAM은 FPGA 모듈의 아랫 부 분에 배치하고 있으며, 보드 아랫 쪽에도 하나가 장착되어 있어 총 2개로 구성되어 있 습니다.

> **그림 3-14** · SRAM 블록 구성

**2)** 동작

여기서 제공되는 SRAM (Static Random Access Memory)과 Flash Memory는 각각 FPGA I/O와 연결되어 있기 때문에 SRAM을 제어하기 위해서는 FPGA 핀 설정과 제어 회로를 설계해 주어야 합니다. 이렇게 컨트롤 핀 설정을 통하여 메모리 영역의 제어가 이루어 집니다.

다음 그림에서는 SRAM에서의 READ와 WRITE에 대한 동작 사이클의 모습을 보여주고 있습니다. SRAM의 동작은 Read시 Address에 해당하는 값을 인가한 뒤 SRAM_CS 및 SRMA_OE 에 대한 제어 핀을 0 으로 인가함과 동시에 데이터 라인에서 해당되는 번지에 저 장된 값이 출력 되게 됩니다. 또한 Write는 이와 반대로 Address와 32 bit 데이터 라 인에 해당하는 값을 인가 한 뒤 SRAM_CS 및 SRAM_WR에 대한 제어 핀을 0 으로 변경함과 동시에 32 bit 데이터 값이 해당하는 번지에 저장되게 됩니다.

**3)** 회로

SRAM은 위의 그림과 같은 회로를 구성하고 있습니다. 여기에서는 18개의 Address라 인과 32개의 Data 라인으로 구성되어 있고, 3개의 제어 신호를 통해 SRAM을 제어하 고 있습니다. SRAM의 모든 제어 신호는 FPGA 디바이스와 직접 연결 되어 있고, FPGA 디바이스에서 SRAM 핀을 제어하여 내부에 읽고, 쓰고 하는 작업을 하게 됩니 다.
