# 1. 개요

HBE-Combo III는 현대의 전자, 정보통신 산업현장에서 필요로 하는 디지털 논리회로 설계에 대한 학교 교육에서 이론적인 교육환경을 벗어나 이론에서 얻은 결과를 직접 눈으로 확인 할 수 있도록 하는 환경을 제공하기 위한 디지털 논리 회로 설계 실습 장비입니다. 

HBE-Combo III는 산업 현장에서 디지털 회로설계에 많이 적용되고 있는 FPGA와 ARM Processor을 이용하여 사용자가 설계한 회로를 직접 하드웨어를 이용하여 동작 시킴으로 이론교육에서 얻을 수 없었던 여러 가지 동작 현상을 실험을 통해 얻을 수 있으며 이와 아울러 학생들에게 디지털 논리 회로 설계에 대한 흥미를 유발 시킬 수 있습니다. 

본 제품의 COMBO라는 이름은 Altera사와 Xilinx사의 두 회사의 FPGA 디바이스를 모 듈화 하여 제공하고 있습니다. 따라서 한 보드에서 두 종류의 모듈을 선택하여 장착할 수 있는 구성으로 다양한 디바이스를 경험할 수 있도록 제공하고 있습니다. 또한 Processor Module도 ARM9 및 Cortex-M1, Cortex-M3의 다양한 종류의 Processor 모듈을 통해 여러 종류의 디바이스를 하나의 보드에서 경험해 볼 수 있도록 구성하고 있습니다. 

보드에서는 사용자가 원하는 클럭을 손쉽게 사용할 수 있도록 Clock Control Block을 두어 다양한 클럭을 디바이스로 공급해 주고 있습니다. 여기에서는 두 개의 Clock Select SW를 통해 수 십개의 다양한 클럭을 선택하고 공급해 줌으로써 사용자가 설계 시 편리성을 주고 있습니다. 또한 사용자가 가지고 있는 특정 오실레이터를 보드에 장 착하여 사용할 수 있도록 FPGA 모듈에 User Clock을 두고 있습니다. 따라서 이 자리 에 오실레이터를 장착하여 발생되는 특정 클럭을 받아서 사용할 수 있습니다. 

장비에 구성하고 있는 장치들을 살펴보면, VFD(Vacuum Fluorescent Display) 및 고휘 도 LED를 두어 시인성을 더욱 강화하였습니다. 또한 다양한 입력 장치 (버튼 스위치, 버스 스위치)를 사용하여 보드 내에서 직접 제어하여 실험할 수 있게 구성하고 있습니
다. Display 장치로는 Image Sensor와 TFT-LCD를 두어 영상을 입력 받아 화면에 출 력 할 수 있는 장치를 두고 있으며, 또한 OLED및 Dot-Matrix를 구성하고 있어 다양 한 Display 실험도 지원해 주고 있습니다. 또한 온도 및 습도를 측정할 수 있는 온,습 도 센서, USB to Serial 통신 실험을 할 수 있는 USB 포트, 자기센서를 이용한 스텝 모터 구동을 할 수 있도록 구성하였습니다. 또한 보드 내에 50핀 커넥터를 이용하여 다양한 확장 모듈을 장착하여 실험할 수 있도록 구성하고 있습니다. 

HBE-COMBO III를 이용하면 디지털 논리회로 설계의 기본의 이론적인 부분을 벗어나 다양한 응용 모듈과 장치들을 이용한 설계에서 더 높은 회로 설계의 기술을 익히고 배우게 될 것입니다. 제품에 장착되어 있는 최신의 디바이스와 대용량의 디바이스로 설계에 대한 제약이 없이 설계를 할 수 있습니다. 또한 두 회사의 디바이스를 사용하 여 설계하는 회사의 제약 없이 회로를 설계 할 수 있는 방법을 익히게 될 것입니다.


## 1.1 제품 특징

▪ 새로운 디바이스를 이용한 장비 구성 최신의 Embedded Process(ARM) 및 FPGA 디바이스를 사용한 SoC 환경을 지원하여 장비의 동작을 실험 실습 할 수 있는 기능을 제공하고 있습니다. 또한 영상처리 등의 고용량의 로직 설계가 가능하도록 대용량의 FPGA 디바이스를 기본으로 제공하고 있 습니다. ▪ SoC 환경을 지원한 실습 실험 ST 및 ACTEL사의 ARM 프로세서를 사용한 두 종류의 모듈을 이용하여 다양한 응용 실험을 할 수 있는 구성으로 AMBA bus를 통해 FPGA 디바이스와 연계한 실험 실습 환경을 제공하고 있습니다. ▪ Altera, Xilinx 디바이스의 모듈화 FPGA 디바이스의 유연성과 확장성을 고려하여 Altera와 Xilinx 디바이스의 교체 사용 이 가능하도록 모듈화 하였으며 Altera사의 Cyclone II Series와 Xilinx사의 Spartan 3A DSP Series를 사용할 수 있도록 구성하고 있습니다. ▪ 디바이스 모듈의 독립성 FPGA 모듈에서는 디바이스와 Configuration ROM을 같이 두어 모듈의 Configuration ROM에서 한번의 프로그램으로 다음의 전원 인가 시 Configuration ROM에 의한 데모 동작을 할수 있도록 구성하고 있습니다. 또한 별도의 오실레이터를 모듈에 장착하여 사용이 가능하도록 구성하고 있으므로 모듈에 전원 공급만으로 단독 사용이 가능하게 구성하고 있습니다. 또한 Processor 모듈에서는 Processor 디바이스 및 Memory, 통신 포트를 하나의 모 듈로 구성하고 있어 전원 공급으로 모듈의 단독 동작이 가능하도록 구성하고 있습니 다. ▪ Clock Control Block을 이용한 클럭 이용 베이스 보드에 있는 두 개의 오실레이터를 통해 발생된 클럭을 클럭 발생 디바이스와 CPLD 디바이스를 통해 0 ~ 250MHz의 클럭을 발생하여 FPGA 디바이스로 전달됩니 다. 이 클럭은 두 개의 Clock Select 스위치를 통해 선택할 수 있고, 선택된 클럭의 종류는 Clock Select의 7-Segment를 통해 어떠한 클럭이 FPGA로 전달이 되는지 확 인할 수 있습니다. 또한 FPGA 모듈에서는 별도의 User Clock를 두고 있어, 베이스 보드의 Clock Control Block에서 발생하는 클럭 이외의 특정 오실레이터를 장착하여
사용할 수 있습니다. 이 User Clock는 FPGA 모듈 상단에 오실레이터를 장착할 수 있 는 곳을 두고 있으며, 여기에 있는 오실레이터 값을 입력 받기 위해 User Clk EN 스 위치는 On 해 주어야 장착된 오실레이터에서 클럭값이 FPGA 디바이스로 전달이되 어 사용자가 활용할 수 있습니다. 이 스위치는 사용하지 않을 시 Off 상태로 두어 사용하시기 바랍니다. ▪ 장비의 확장성 장비에서는 50pin x 2의 확장 포트를 두고 있어 HBE-Combo III에서 제공하는 확장 보드를 연결하여 베이스 보드에서 지원하지 않는 장치들에 대한 실험을 할 수 있으며 이외에 별도의 장치를 연결하여 제어할 수 있도록 구성하고 있습니다. 이 확장 커넥터 를 일반 양면 기판에 호환할 수 있도록 배치 되어 있으며, 플렛 케이블을 통해 창치를 연결하여 사용할 수 있습니다. ▪ 테마 별 실습 지원 특색이 있는 장치들을 테마 별로 멀티미디어, 센서, 모터등으로 분류하여 한 보드에 구성하고 있어 다양한 프로젝트별 실험 실습 환경을 시험해 볼 수 있도록 지원해 주 고 있습니다. ▪ 손쉬운 프로그래밍 작업 다양한 작업 (FPGA Download, PROM Program)에 사용되는 전용 케이블 모듈을 이용 하여 PC와 장비를 연결하여 손쉽게 프로그램 할 수 있도록 구성하였습니다.

## 1.4 보드 구성 및 각 부분 명칭

> **그림 1-2** · HBE-COMBO III 보드구성 및 각 부분 명칭

**1)** FPGA 모듈

Altera 및 Xilinx FPGA 디바이스 모듈을 겸용으로 장착 사용 가능하도록 커넥터로 구 성하였습니다. 따라서 사용자가 사용하려는 FPGA Module을 선택 장착하여 사용이 가 능합니다. 여기에서 선택하는 모듈에 따라서 설계 소프트웨어도 달리 해 주어야 합니 다. 이렇게 설계된 환경은 전용 다운로드 케이블을 이용하여 디바이스 모듈의 JTAG 커넥터로 FPGA 디바이스와 Configuration PROM에 다운할 수 있습니다. 따라서 FPGA 모듈은 전원 공급을 통해 디바이스에서 다운이 가능하게 구성하였습니 다. 또한 FPGA 디바이스는 RAM 타입의 디바이스로 전원 OFF시 디바이스 내부의 데 이터가 사라짐으로 다시 전원을 ON 하더라도 이전의 동작이 계속 유지가 되지 않습니
다. 그래서 전원을 켤 때마다 디바이스에 재 프로그램 해 주어야 합니다. 이런 불편한 점을 보완하기 위해 별도의 Configuration ROM을 두어, 한번의 프로그램 만으로 데이터가 사라지지 않고 RECONFIG 버튼을 통해 Configuration ROM을 통해 미리 저장된 데이터를 넘겨주어 동작이 가능하게 구성을 하였습니다. 현재 FPGA 모 듈 에서 사용하는 Configuration ROM은 Altera (EPCS Series), Xilinx (XCF Series)를 사용하고 있습니다.
**2)** Embedded Processor 모듈

FPGA 디바이스와 연동하여 사용할 수 있는 ARM Processor 모듈을 장착하여 사용할 수 있도록 구성하고 있습니다. 이 모듈은 단독 동작이 가능하도록 구성되어 있어 프로 세서 및 USB, UART, Ethernet을 통한 통신 실험이 가능하고 FPGA 디바이스와 AMBA 버스를 통한 연동 실험으로 장비 내부에 있는 장치들의 동작 실험을 구현해 볼 수 있습니다. 이 모듈은 출고 시 Boot-loader이 올려진 상태이기 때문에 UART를 통 한 Processor 제어 실험이 가능한 상태입니다.
**3)** 클럭 제어 블록

메인 클럭은 Base Board에서 FPGA 디바이스로 전달해 주고 있습니다. 클럭 발생은 보드의 두 개의 오실레이터를 통해 발생된 클럭을 소스로 컨트롤 디바이스를 통해 0 ~ 250 MHz의 클럭을 발생하고 있습니다. 클럭 제어 디바이스로는 ATmega16L과 CPLD를 통해 제어를 하고 있으며, 출고 시 프로그램 되어서 출고가 됩니다. 클럭 제어 블록에서 발생되는 클럭의 선택은 두 개의 Clock Select 스위치를 통해 선 택해서 사용할 수 있습니다. 이 스위치를 통해 여러 개의 클럭을 선택할 수 있습니다. 이 스위치를 돌리면 Clock Select의 7-Segment를 통해 현재 어떤 클럭이 선택되었는 지 확인할 수 있습니다. 또한 모듈에 별도의 User Clock을 달아서 사용할 수 있도록 구성을 해 놓았습니다. 사용자가 사용하려는 오실레이터의 값이 그대로 FPGA 디바이스에 전달되어 사용을 할 수 있도록 구성이 되어 있습니다. 따라서 사용자가 원하는 클럭을 오실레이터를 꽂 으면 그 클럭이 바로 디바이스에 전달되어 사용이 가능합니다. 이 User Clock은 옆에 User Clk EN 스위치를 두어, 사용하는 오실레이터가 없을 때 스위치를 OFF 시켜서 클럭 핀을 안정화 시켜 놓았습니다. 사용하는 클럭은 몇 개의 클럭 입력 전용 핀을 이 용해서 입력을 받고 있으므로 메인 클럭과 User Clock을 동시에 받아서 회로를 설계 할 수 있습니다.
**4)** Piezo

특정 주기의 클럭 소스를 인가할 경우 멜로디를 출력하는 장치입니다. 10KHz ~ 1Hz 의 클럭 소스를 사용하여 다양한 멜로디를 출력 할 수 있습니다. 따라서 주파수가 높 은 수록 고음이 낮을수록 저음이 출력이 됩니다. 또한 Piezo EN의 딥 스위치를 두어 사용하지 않은 때 Piezo로 입력되는 잡음에 의해 소리가 나는 것을 방지 하도록 구성 하고 있습니다.
**5)** Step Motor

4개의 데이터 라인을 통해 1상 여자 방식, 2상 여자 방식, 1-2상 여자 방식으로 모터 를 구동하게 됩니다. 따라서 이러한 데이터의 신호에 따라서 모터가 가지고 있는 정해 진 각도에 따라 모터 축이 회전하는 원리를 가지고 있는 모터를 구성해 놓았습니다. 또한 모터의 회전을 감지하기 위해 자기센서를 부착하고 있어, 모터의 구동에 다양한 방법으로 실험 해 볼 수 있도록 지원해 주고 있습니다.
**6)** TFT-LCD

장비에 장착된 TFT-LCD는 320xRGBx240의 16.7M의 컬러를 지원해 주는 3.5 TFT-LCD를 사용하고 있습니다. 백 라이트 LED 및 24bit의 RGB 데이터 라인을 통해 화면을 표시하는 방식으로 장치를 제어하게 됩니다. 현재 사용하고 있는 TFT-LCD는 초기 전원 인가 시 SPI를 통해 TFT-LCD를 통작하기 위한 환경 설정을 해 주어야 합 니다. 이러 한 작업은 TFT-LCD 보드에 장착된 ATmega16에서 이러한 환경 설정을 해 주게 됩니다. 따라서 초기 전원 인가와 동시에 TFT-LCD 환경 설정이 자동으로 이 루어 지고 사용자는 24bit 데이터 라인을 통해 제어를 하면 TFT-LCD가 동작하게 됩 니다.
**7)** Image Sensor

TFT-LCD 모듈에 장착하여 LCD와 연동하여 사용하는 Image Sensor는 영상을 입력 받는 창치 입니다. 이것은 130만 화소의 출력을 가진 장치로써 54 MHz의 클럭 입력 에서 최대 15 ~ 30 프레임의 성능을 가지고 있습니다. 또한 최대 1280H x 1024V의 사이로 화면을 출력할 수 있습니다. 또한 저 전압 저 전류 구동 방식으로 휴대폰 등의 소형 기기에 많이 이용되고 있는 장치입니다.
**8)** VFD

16문자 x 2라인을 출력할 수 있도록 구성된 VFD 모듈입니다. VFD란 진공 형광 표시 장치[Vacuum Fluorescent Display]로써 저속 전자선에 의한 형광체의 여기 발광 현상 을 이용한 표시 장치 입니다. 따라서 HBE-COMBO의 Text LCD 보다 도트 자체적으 로 발광을 하기 때문에 밝기 면에서 우수하여 시인성이 뛰어나고 응답 속도가 빠른 특징이 있습니다.
동작은 영문, 숫자, 특수문자 등을 문자표를 보고 데이터 값을 보내서 표시가 가능합 니다. 또한 코드의 수정으로 문자의 밝기를 4가지 모드로 조절할 있는 특징이 있습니 다.
**9)** 7-Segment(1, 8 digit)

장비에 구성하고 있는 7-Segment는 1 digit와 8 digit로 구성이 되어 있습니다. 따라 서 1 digit의 Segment를 통해 숫자를 표시할 수 있고, 8 digit를 통해 8개의 7- Segment를 스캔 방식에 의해 구동할 수 있는 방식으로 두 가지의 제어 방식을 통해 7-Segment를 제어할 수 있습니다. 1 digit 방식은 8개의 라인으로 하나의 7-Segment 를 제어하고 Array 방식으로 구성된 8개의 7-Segment는 스캔 방식을 통해 8개의 데 이터 라인을 공통으로 사용하기 때문에 16개의 핀으로 장비를 제어하고 있습니다.
**10)** High light LED

총 16개의 딥 타입의 고휘도 LED로 구성되어 있습니다. 이 LED는 고휘도 방식으로 보다 밝은 빛으로 작동하고, 윗 면이 평평하게 깍여 있는 구조로 되어 있어서 모든 방 향에서 빛을 감지할 수 있습니다.
**11)** Reset Switch

이 장치는 별도의 버튼 스위치로 소스 작성 시 Reset 용도로 사용할 수 있는 스위치 로 동작 시 0 의 값이 FPGA로 전달이 되게 됩니다.
**12)** Dip Switch

장비에서는 입력 스위치의 한 종류로 8개의 딥 스위치를 통해 입력 장치로 이용할 수 있도록 구성하고 있습니다. 이 스위치를 위로 올리면 스위치는 On이 되게 되며, 스위 치가 On이 되면 1 의 값이 FPGA로 전달되게 됩니다.
**13)** Button Switch

입력 장치의 한 종류로 16개의 버튼 스위치를 두고 있습니다. 0 ~ F까지의 16 종류로 사용할 수 있도록 구성이 되어 있으며, 누르기 편한 스위치의 강도와 모양을 가진 스 위치를 선택하여 장착하고 있습니다. 또한 16개의 스위치에는 채터링을 방지하기 위한 회로가 추가 되어 있으며, 버튼을 누르면, 1 의 값이 FPGA로 전달됩니다.
**14)** 온 습도 센서

디지털 방식으로 구성하는 이 센서는 온도 및 습도에 대한 정보를 측정하여 FPGA로 전달을 해 주게 됩니다. 0 ~ 100%의 습도 및 -40 ~ 123℃의 온도를 측정할 수 있는 센서로써, FPGA에서 각 센서값을 요청에 의해 측정된 값을 전달하게 됩니다. 따라서 FPGA에서는 이러한 값을 게산하여 현재 장비가 있는 환경을 측정 할 수 있습니다.
**15)** SD Card Connector

장비에서는 SD 메모리 카드의 소켓을 통한 인터페이스 환경을 제공하고 있습니다. 따 라서 SD 메모리 커넥터를 통해 SD 메모리에 데어를 저장하고 읽어 올 수 있도록 지 원해 주고 있습니다.
**16)** UART port

장비와 PC간의 Serial 통신을 지원하기 위해 9핀 시리얼 케이블을 장착하여 통신할 수 있는 포트를 지원해 주고 있습니다. 이 포트를 통해 PC와 장비간의 데이터를 주고 받을 수 있으며 PC를 통한 장비 제어 실험도 할 수 있는 환경을 구성하고 있습니다.
**17)** USB to Serial port

시리얼 통신을 지원하기 위한 포트로써 사용하는 PC에 Serial port가 없을 때 이 포트 를 통해 활용할 수 있습니다. 이것은 USB를 통한 시리얼 통신 지원 장치로 FT232 디 바이스를 통해 이러한 작업을 할 수 있습니다. 이 장치는 사전에 PC에서 디바이스를 인식하기 위해 드라이버를 설치해 주어야 합니다. 이것은 http://www.ftdichip.com/ 에서 윈도우 환경에 맞는 드라이버를 다운받아 설치해 주시면 됩니다.
**18)** PS/2 port

PC의 입력 장치로 사용되는 PS/2 키보드나 마우스를 연결해 키보드 컨트롤러나 마우 스 컨트롤러를 설계해 볼 수 있는 PS/2 커넥터로 구성되어 있습니다.
**19)** USB Download port(옵션기능)

FPGA 디바이스를 다운로드하기 위한 Port로써 별도의 USB 다운로드 케이블과 연결 하여 사용할 수 있는 포트입니다. USB 다운로드 케이블은 PC의 Parallel Port 이외에 USB Port에 연결하여 FPGA 디바이스를 다운로드 할 수 있도록 지원해 주는 장치로써 옵션으로 선택할 수 있는 장치입니다. 이 케이블을 분실을 방지하기 위해 보드 내부에 장착하고 PC와는 USB 케이블만 연결하여 사용할 수 있도록 지원해 주고 있습니다. 따라서 다운로드 시 간편하게 사용할 수 있도록 지원해 주고 있습니다.
**20)** 확장 포트

장비에서는 확장 커넥터를 통해 프로젝트별로 구성되 다양한 보드를 장착하여 실험을 할 수 있도록 구성하고 있습니다. 따라서 기본인 Peripheral 보드와, Motor, Sensor, 그리고 멀티미디어로 구성된 MMC 보드를 장착하여 실험 실습을 진행할 수 있도록 지 원해 주고 있습니다. 또한 보드에서는 이러한 확장 보드 이외에 사용자가 가진 별도의 장비와 연결하여 사용할 수도 있습니다. 따라서 장비에서 제공되어지는 장치 이외의
장비도 연결하여 실험이 가능하도록 지원해 주고 있습니다.
**21)** 그 밖의 장치(Memory)

총 8M Bit의 SRAM과 총 16M Bit의 Flash Memory로 구성되어 있으며 SRAM과 Flash Memory는 32 bit의 데이터 라인으로 통신할 수 있도록 지원해 주고 있습니다. 또한 두 메모리간의 Address 및 Data 라인이 공통으로 연결되어 구성되어 있습니다. 사진 에서는 FPGA 모듈 밑에 위치하고 있습니다.
