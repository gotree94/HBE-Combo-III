# 9. ARM Processor Module Getting Started

> 출처 : 「HBE-Combo III로 배우는 ARM 기반 SoC 설계_OCR」 2장 「9. ARM Processor Module Getting Started」 (원본 도서 109~128쪽 · OCR 인식)

HBE-Combo HI ARM Processor의 개발 환경 설정은 타겟 보드가 되는 본 장비와 리눅스 및 윈도우가 설치된 호스트 PC를 설정해야 한다. 먼저 하드웨어의 설정을 하고, 호스트 PC의 개발환경 설정과 필요한 유틸리티 등을 설치하면 그때부터 HBE-Combo III ARM Processor 이용한임베디드 리눅스의 개발, 연구를 진행할 수 있다.

## 9.1. 호스트PC에서의 Linux 개발 환경 설정

Linux에서는 리눅스 커널 및 파일시스템을 작성하기 위해서 크로스 컴파일러를 비롯 하여 바로 작성한 커널 및 램 디스크를 네트워크를 통해 테스트 하기 위한 tftp, 통신 데몬 등을 설치해야 한다. 리눅스가 설치되지 않은 PC에 리눅스를 설치하려면, 백업하는 시간, 리눅스를 설치하는 시간 심지어는 윈도우도 다시 설치해야 하는 시간이 소요된다. 이런 시간만 하더라도 3-4시간이 소요되며, 리눅스가 설치되지 않는 PC도 있어 이를 설정하는데 상당한 시간이 소요되게 된다. 이를 대비해서 우리는 PC에서 또 다른 PC를 만들어 주는 시스템 가상머신 인WMware Player를 사용할 것이다. 이 프로그램을 이용하면 윈도우를 사용하면서 동시에 리눅스도 사용할수 있는 장점이 있기 때문에 개발환경이 매우 편리해 진다.

### (1) VMware 설치

VMware 홈페이지 (http://www.vmware.com/) 에서 직접 다운로드 받을 수도 있지만, 제공하는DVD에서 설치파일을 하드로 복사해서 설치를 실행한다. 설치과정은 서너 번의 클릭으로 간단히 끝나므로, 어렵지 않게 진행할 수 있을 것이다.처음 실행화면에서 Next 를 눌러 다음단계로 넘어가자.설치할 폴더를 선택하는 단계이다. 기본설정으로 하고, 다음단계로 넘어가자. 그 다음은 단축아이콘을 생성 여부를 물어보는 단계이다. 빠른 시작, 바탕화면, 프로그램폴더 3군데를 물어보므로, 개인 취향에 따라 설정하도록 한다. 여기서는 기본설정으로 진행한다.설치여부를 물어보는 단계이다. Install 을 눌러 설치를 시작하자. 설치는 PC사양에 따라 다르지만, 3분에서 5분 정도 소요된다.설치가 완료되면, finish를 눌러 설치를 마치도록 한다.
