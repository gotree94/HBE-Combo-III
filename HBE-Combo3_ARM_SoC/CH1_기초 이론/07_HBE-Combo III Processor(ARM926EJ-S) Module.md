# 7. HBE-Combo III Processor(ARM926EJ-S) Module

> 출처 : 「HBE-Combo III로 배우는 ARM 기반 SoC 설계_OCR」 1장 「7. HBE-Combo III Processor(ARM926EJ-S) Module」 (원본 도서 63~68쪽 · OCR 인식)

## 7.1. 개요

HBE-Combo in를 지원하는 여러가지 Processor 모듈 중 이 교재에서는 ARM926EJ-S 프로세서가 구성되어 있는 ARM Processor 모듈을 사용하여 제어하는 방법을 설명하고 있다.이 ARM926EJ-S 프로세서 모들은 ST에서 생산하는 SpearHead라는 이름의 ARM 프로세서가내장된 디바이스를 사용한다. 이 디바이스는 ARM926EJ-S Core 뿐만 아니라 UART 통신,Memmory Controller, USB Controller등이 내장되어 쉬운 개발 환경을 지원해 준다. 또, AHBBus를 외부로 확장할 수 있도록 구성되어 있기 때문에 AMBA Bus Interface를 통한 다양한 주변 장치를 붙여 제어할 수 있도록 구성되어 있다.
