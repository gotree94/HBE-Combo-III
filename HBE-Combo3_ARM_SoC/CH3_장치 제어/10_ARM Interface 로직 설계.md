ARM Processor 모듈과 HBE-Combo III의 주변장치를 연결하기 위하여 FPGA 모듈에 이 두 블록을 연결하는 인터페이스 로직을 설계하여야 하는데, 제어하는 신호가 많고 복잡하기 때문에인터페이스 로직을 설계하기가 쉽지 않다.한백전자에서는 ARM Processor 모듈에서 나오는 AHB 신호를 간소화 하여 간단하게 인터페이스 로직을 설계할 수 있는 HB_C3_SoC를 제공하고 있다. HB_C3_SoC로직은 ARM Interface 로직으로 사용자가 제어할 주변 장치에 대한 블록만을 추가하여 ARM Processor 모듈에서 쉽게제어할 수 있도록 도와주는 기능을 한다.이 HB_C3_SoC는 아래 그림과 같이 quartus와 rtl2| 두개의 폴더로 구성된다.10. ARM Interface 로직 설계
