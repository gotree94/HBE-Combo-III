# 16. Dot Matrix 제어

> 출처 : 「HBE-Combo III로 배우는 ARM 기반 SoC 설계_OCR」 3장 「16. Dot Matrix 제어」 (원본 도서 245~270쪽 · OCR 인식)

16.1.개요이 장에서는 ARM Processor 모듈을 제어하여 Dot Matrix를 제어하는 예제가 구성되어 있다.HBE-Combo ffl 장비에 구성된 Dot Matrix는 10열 14행의 구조이다. 이 구조에서 각 Dot를 제어하여 문자나 그림을 표시할 수 있다. 어떻게 보면 여러 개의 LED를 제어하여 문자를 표시한다는 점에서 7-Segment와 비숫하다. 다만, 7-Segment보다 더 많은 L티3를 이용하여 문자를 표시하기 때문에 표현할 수 있는 가짓수가 더 많고, 그에 따른 제어 방법이 좀 더 복잡하다.예를 들어 아래와 같이 5 X 7 Dot Matrix를 제어하여 A라는 문자를 나타내고자 하였을 때, 제어하는 라인은 DOT_SCAN과 DOT_DATA 이렇게 총 12라인（가로 5, 세로 7）을 제어해야 한다.DOT_SCAN03 47-Segment Array를 제어할 때와 비숫한 방법으로 제어하는데, DOT_SCAN 데이터 선을 이용하여 표시하고자 하는 Dot Matrix의 라인을 선택하고, 여기에 표시하고자 하는 데이터의 값을입력해 주면 된다.처음 라인에 데이터를 쓰기 위해서 DOT_SCAN[0:4]에 "10000"이라는 값을 전달해 주고, 이 때표시하고자 하는 데이터 라인인 DOT_DATA[0:6]에 "0011111"의 값을 전달해 준다. 두 번째 라인을 선택하기 위해 DOT_SCAN[0:4]에 "01000"이라는 값을 전달해 주고, DOT_DATA[0:6]에"0101000"의 값을 전달해 준다. 같은 방법으로 나머지 3개의 라인도 DOT_SCAN과 DOT_DATA를 제어하여 값을 전달해 주고, 이 DOT_SCAN을 선택하는 순서를 빠르게 진행시키면 5 x 7Dot Matrix에 A라는 문자가 표시되는 것으로 나타나게 된다.0vl<alloa위에서 데이터에 전달하는 값을 정리하면 아래 표와 같다.구 분DOT_SCAN[0:4]DOT_DATA[0:6]0 열1000000111111 열0100001010002 열10010003 열01010004 열0011111위에서 5 x 7 Dot Matrix를 제어하는 방법을 설명하였는데, 장비에 구성된 10 x 14 Dot Matrix도 같은 방법으로 제어할 수 있다. 다만, DOT_SCAN과 DOT_DATA의 데이터 라인이 늘어났을뿐이다.아래 표는 ARM Processor 모듈에서 Dot Matrix를 제어하기 위하여 접근해야 하는 번지를 나타낸 것이다.
