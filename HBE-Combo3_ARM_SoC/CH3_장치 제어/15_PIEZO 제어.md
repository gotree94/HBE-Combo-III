# 15. PIEZO 제어

> 출처 : 「HBE-Combo III로 배우는 ARM 기반 SoC 설계_OCR」 3장 「15. PIEZO 제어」 (원본 도서 227~244쪽 · OCR 인식)

## 15.1. 개요

이 장에서는 ARM Processor 모듈을 제어하여 PIEZO를 제어하는 예제를 설명하고 있다.소리를 출력하는 장치로 쉽게 생각할 수 있는 것이 스피커이다. 스피커는 소리의 높낮이와 주파수를 조정하여 원하는 소리를 출력할 수 있도록 구성되어 있다. 이 외에도 PIEZO（압전 부저）라는 소리의 높낮이는 조절하지 못하지만 주파수를 조정하여 소리를 발생할 수 있는 출력장치가 있다. PIEZO는 간단하게 MIDI 음이 출력되는 PC본체에 붙어 있는 스피커라고 생각하면된다. 이 PC 스피커는 다양한 소리는 내지 못하지만 멜로디 등의 소리나 경고음 등을 표현 할수 있다.PIEZ◦는 디지털 신호 1에 해당하는 입력 레벨의 음성 주파수대의 펄스 신호를 입력하면 해당주파수 소리를 출력하게 된다. 따라서 PIEZO에 1의 값만 입력함으로써 소리를 낼 수 있는 것이 아니라, 소리에 해당하는 주파수를 입력하여 소리를 발생할 수 있다. 또, PIEZO는 일반적인주파수 특성에 의해 약 lOKHz 이상의 주파수에서는 소리를 내지 않게 된다. 이것은 가청 주파수대역 이상의 소리가 나오기 때문이다.아래의 표는 PIEZO를 동작시키기 위한 주파수를 나타낸 것이다. 아래 표에서 3 옥타브가 우리가 일반적으로 사용하는 옥타브이다.음 계옥타브도130.8128 Hz261.6256 Hz523.2511 Hz레146.8324 Hz293.6648 Hz587.3295 Hz미164.8138 Hz329.6276 Hz659.2551 Hz파174.6141 Hz349.2282 Hz698.4565 Hz솔195.9977 Hz391.9954 Hz783.9909 Hz라220.0000 Hz440.0000 Hz880.0000 Hz시246.9417 Hz493.8833 Hz987.7666 Hz아래의 표는 ARM Processor 모듈에서 PIEZO를 제어하기 위한 HADDR의 주소 번지와, FPGA에서의 주소 번지 그리고, HDATA와 PIEZO와의 연결을 나타내고 있다.ARM 주소FPGA 주소설 명Ox 20D0 0000Ox 00D0 0000HDATA[0] : Enabled) / Disable(O)HDATA[1] : Melody(l) / GPIO(O)Ox 20D1 0000Ox 00D1 0000GPIO : i_PIEZO <= HDATA[0]Ox 20D2 0000Ox 00D2 0000Memory : Melody <= HDATA[7:0]위의 표에서 Ox 20D0 0000 번지일 때의 데이터는 이 PIEZO 제어 로직의 사용 여부와 PIEZO를 직접 제어할 것인지, 아니면 음계 데이터만 넣어 멜로디가 나오도록 할 것인지를 설정한다.Ox 20D1 0000 번지의 데이터는 PIEZO의 Control 데이터 중 HDATA［이이 T의 값을 갖고 있고,HDATA［1］이 '0'의 값을 갖고 있을 때에 PIEZO를 ARM Processor 모듈에서 직접 제어하는 데이터로 PIEZO 주파수를 전달하도록 한다.Ox 20D2 0000 번지의 데이터는 도레미파솔라시도에 각각 해당하는 8비트 데이터이다.즉, ARM Interface 로직에서는 PIEZ◦를 직접 제어하거나, FPGA에서 기본 제어 로직을 설계하고 ARM Processor 모듈에서 음계 데이터를 입력 받아 출력되어 있다.
