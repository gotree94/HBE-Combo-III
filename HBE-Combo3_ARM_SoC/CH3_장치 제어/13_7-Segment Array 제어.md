## 13.1. 개요

이 장에서는 ARM Processor 모듈을 제어하여 7-Segment Array를 제어하는 예제가 구성되어있다.7-Segment Array는 7-Segment와 데이터를 제어하는 방법은 같다. 즉 8개의 a,b,c,d,e,f,g,h의데이터에 값을 넣으면 그에 해당하는 문자 또는 숫자가 7-Segment에 표시됩니다. 단지, 7-Segment의 Common 단자에 의해서 8개의 7-Segment 중 표시하려고 하는 7-Segment를 선택하여 문자 또는 숫자를 표시한다.아래 그림과 같이 4개의 7-Segment Array를 제어하는 방법을 설명하면, 아래의 4개의 7-Segment가 묶인 7-Segment Array를 제어하는 데이터 라인은 8비트의 데이터 선과 4비트의Common 단자이다. 숫자를 표시하려고 하는 7-Segment를 '0'이라는 신호로 설정하고, 표시하려는 8 비트 데이터를 연결해 주면 선택한 7-Segment에 숫자가 표시되는 것이다.아래의 첫 번째 그림과 같이, 첫 번째 7-Segment에 숫자 "1"을 표시하기 위해서는 첫 번째의7-Segment만을 선택하기 위하여 4비트 Common 단자에 "0111"이라는 데이터를 전달해 주고,8비트의 "01100000" 데이터를 전달해 주면 첫 번째 7-Segment에 T이 표시된다. 나머지 2, 3,4도 같은 방법으로 C이nmon 단자를 제어하고，선택한 7-Segment에 맞는 데이터를 전달해 주는 방법으로 숫자를 표시할 수 있다. 그리고, 이 Common 단자를 순서대로 선택하는 것의 속도를 빠르게 함으로써,4개의 7-Segment에 동시에 데이터가 표시되는 효과를 나타낼 수 있다.ESSSHS/ iSStSSSlHSS/。日。EW아래의 표는 ARM Processor 모듈에서 7-Segment를 제어하기 위한 HADDR의 주소 번지와,FPGA에서의 주소 번지 그리고, HDATA와 7-Segment와의 연결을 나타내고 있다.ARM 주소FPGA 주소설 명Ox 2030 0000Ox 0020 0000HDATA[0] : Enabled) / Disable(O)HDATA[1] : Font(l) / GPIO(O)Ox 2031 0000Ox 0021 0000GPIO : i_SEG_COM <= HDATA[15:8]i SEG DATA <= HDATA[7:0]Ox 2032 0000Ox 0022 0000FONT : SEG_F1 <= HDATA[15:12]SEG_F2 <= HDATA[11:8]SEG.F3 <= HDATA[7:4]SEG F4 <= HDATA[3:0]Ox 2032 0000Ox 0023 0000FONT : SEG_F5 <= HDATA[15:12]SEG.F6 <= HDATA[11:8]SEG.F7 <= HDATA[7:4]SEG F8 <= HDATA[3:0]위의 표에서 Ox 2030 0000 번지일 때의 데이터는 이 7-Segment 제어 로직의 사용 여부와 7-Segment를 직접 제어할 것인지, 아니면 16진수의 값을 넣었을 때 출력하도록 할 것인지를 결정하기 위한 7-Segment Control 데이터 이다.Ox 2031 0000 번지의 데이터는 7-Segment Control 데이터 중 HDATA［이이 T의 값을 갖고 있고, HDATA［1］이 '0'의 값을 갖고 있을 때에 7-Segment Array에 표시하기 위한 8비트의 데이터와 8비트의 Common 단자의 값이다.
