## 12.1. 개요

이 장에서는 ARM Processor 모듈을 제어하여 7-Segment < 제어하는 예제가 구성되어 있다.HBE-Combo III 장비에는 1 개의 7-Segment와 8개의 7-Segment가 연결되어 제어되는 7-Segment Array가 구성되어 있는데, 이 장에서는 이 중 1개의 7-Segment를 제어하는 것을 설명한다.7-Segment 는 간단하게 말하면 8 개의 L티D 가 모여서 문자의 모양을 표시하는 장치이다.7-Segment 는 8 개의 LED 를 편의상 아래 그림과 같이 a,b,c,d,e,f,g,h 로 나누어 설 명한다. 즉 이7-Segment 2| 8 개 LED 데이터 라인에 a~h 의 순서로 "01100000" 의 데이터가 연결되면T이 표시되게 되는 것이다. 다른 문자 또는 숫자도 같은 방법으로 표시한다..아래의 표는 ARM Processor 모듈에서 7-Segment를 제어하기 위한 HADDR의 주소 번지오卜,FPGA에서의 주소 번지 그리고, HDATA와 7-Segment와의 연결을 나타내고 있다.ARM 주소FPGA 주소설 명Ox 2020 0000Ox 0020 0000HDATA[0] : Enable(l) / Disable(O)HDATA[1] : Font(l) / GPIO(O)Ox 2021 0000Ox 0021 0000Font : REG_SEG_FONT <= HDATA[3:0]Ox 2022 0000Ox 0022 0000GPIO : i_SEG <= HDATA[7:0]ee위의 표에서 Ox 2020 0000 번지일 때의 데이터는 이 7-Segment 제어 로직의 사용 여부와 7-Segment# 직접 제어할 것인지, 아니면 16진수의 값을 넣었을 때 출력하도록 할 것인지를 결정하기 위한 7-Segment Control 데이터 이다.Ox 2021 0000 번지의 데이터는 7-Segment Control 데이터 중 HDATA［이이 T의 값을 갖고 있고, HDATA［1］이 T의 값을 갖고 있을 때에 7-Segment에 표시하기 위한 16진수 데이터 값이다.Ox 2022 0000 번지의 데이터는 7-Segment Control 데이터 중 HDATA［이이 T의 값을 갖고 있고, HDATA［1］이 '0'의 값을 갖고 있을 때에 7-Segment에 표시하기 위한 8비트의 데이터이다.이 8비트의 데이터는 7-Segment의 display 데이터 라인과 연결된다.즉，이 ARM Interface 로직에서는 7-Segment를 직접 제어하거나, 16진수 값을 전달해서 제어하는 두 가지 방법을 모두 지원한다.
