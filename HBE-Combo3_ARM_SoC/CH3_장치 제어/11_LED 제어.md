## 11.3. ARM 제어 C아e 설계

리눅스에서는 Ox 2010.0000 번지에 데이터를 입력하게 되면, 그 데이터가 FPGA로 전송되어LED를 점등하게 된다. 하지만, 리눅스에서는 사용자 영역과 커널 영역이 있는데, 우리가 사용하는 사용자 영역 에서는 직접적으로 메모리에 접근할 수가 없다. 그래서 물리주소를 응용프로그램에서 사용할 수 있게 물리 주소를 지정하는 가상주소를 생성해 주는 mmap 함수를 사용해야 한다.소스코드를 작성하기 전에, mmap사용법에 대해 알아보자.함수 원형 :void * map(void *start, size t length , int prot, int flags, int fd, off t offset);mmap 함수는 fd로 지정된 파일（또는 다른 객체）에서 offset을 시작으로 length 바이트만큼을start 주소로 대응한다. start주소는 단지 요구 주소이며, 대부분 커널이 결정해서 해당 주소를n『i알려주므로, 보통 0으로 지정한다. mmap 함수가 성공적으로 실행되면, 해당 주소에 대한 시작주소를, 실패하면 N내丄을 리턴한다.prot 인자는 원하는 메모리 보호모드를 설정한다. 해당 비트는 아래와 같다PROT_READ : 페이지 읽기 허락PROT_WRITE : 페이지 쓰기 허락PROT_EXEC페이지 실행PROT NONE페이지 접근 불가flags 인자는 대응된 객체의 타입, 대응 옵션과 대응된 페이지 복사본에 대한 수정이 해당 프로세스에만 보일 것인지, 아니면 다른 참조하는 프로세스와 공유 할 것인지를 설정한다. 보통MAP_SHARED를 선택한다.MAP_FIXEDMAP_SHARED: 지정된 주소 이외의 다른 주소를 선택하지 않는다.: 객체에 대응시키는 다른 모든 프로세스와 대응 영역을공유한다.MAP PRIVATE: 다른 프로세스와 대응 영역을 공유하지 않는다.mmap 함수로 지정한 주소공간의 사용이 완료되면, 대응주소를 해제해야 한다. 이때 munmap함수가 이 부분을 담당하게 된다.
